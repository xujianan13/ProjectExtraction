| 范围 | 通过项 |
| --- | --- |
| 核心所有权 | 幂等、逆序清理、提前解除登记、单项异常隔离、停止后迟到登记立即释放 |
| 父子作用域 | 子级取消或清理回调重入父级释放，保留子级先于父级的清理顺序；父级停止时兄弟回调立即失活 |

| 场景 | 退出开始即取消业务令牌、停止玩法更新，异步退出完成后清理；进入失败、强退异常和重复强退；旧进入/退出任务不能破坏新轮次 |
| 普通组件 | 默认隐藏不结束，显式选择禁用结束后重开创建新作用域，外部销毁清理 |
| 窗口 | 缓存重开、重复聚焦、打开失败重试、初始化失败、Close/Destroy 异常、停止后的缓存实例拒绝重开 |
| 池实例 | 复用创建新作用域，旧任务不能写新轮次；外部 Destroy 无需等待查询即结束作用域；回收回调异常和池关闭均清理 |
| 资源 | 已停止时不发起加载；不响应取消的测试代理迟到返回真实租约时立即释放；调用方取消后的空/非空结果不能成功；停止或取消后的进度屏蔽 |
