## 复现

关闭同一工程的 Unity Editor 后，在项目根目录运行：

```powershell
./tools/verify.ps1 -Mode Full -WindowsPlayer -HybridClrSource 'D:\Repositories\ProjectExtraction\DevProject\HybridCLRData\LocalIl2CppData-WindowsEditor\il2cpp\libil2cpp'
```

HybridCLR 参数需指向本机兼容源码；也可不传，沿用正式安装流程。日常修改运行 `./tools/verify.ps1`。Full 创建的副本只放在被忽略的 `verification/unified-reuse`，不改变主工程发布设置，不创建仓库外正式新游戏。

虚拟列表首版为固定尺寸单行/单列；可变高度与网格布局属于后续扩展。这里的结果覆盖本地 Editor、离线资源包与实际执行的 Windows 阶段；真实 CDN、WebGL 和小游戏平台 SDK 真机不在本次范围内。
