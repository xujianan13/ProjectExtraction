# 通用动画播放

## 职责与入口

`GameFramework.AnimatorPlayback` 位于 `Runtime/Utilities/Animation`，包装 Unity `Animator`，提供状态播放、逐帧推进、暂停、倍率、指定进度采样和释放。它是普通 C# 对象，不依赖 `GameEntry` 初始化、ECS、战斗、场景服务或项目状态名。局外角色展示、NPC、场景机关和战斗表现均可使用。

控制器、片段与模型由调用方加载；播放器不负责资源加载或实例销毁。可以使用 `RuntimeAnimatorController` 或 `AnimatorOverrideController`。状态名称与层号由调用方传入，框架没有内置 Idle、Attack 等业务名称。

## 两种时间驱动方式

| 用法 | API | 时间来源 |
| --- | --- | --- |
| 持续播放 | `TryPlay`，随后每帧 `Advance(deltaTime)` | 调用方传入的秒数，按片段时长与速度转换为进度 |
| 显式采样 | `TrySample(stateName, normalizedTime)` | 调用方给定的 0～1 进度；超出 1 截为 1 |

局外展示可在实例创建后设置循环动作：

```csharp
var playback = new AnimatorPlayback(animator);
bool started = playback.TryPlay("Base Layer.Idle", loop: true);
```

每帧调用 `playback.Advance(Time.deltaTime)`；需要不受全局时间缩放影响时传入 `Time.unscaledDeltaTime`。`SetPaused(true)` 冻结本地推进；`TrySetSpeed(1.5f)` 修改播放倍率，倍率为 0 时保持姿态。切换动作再次调用 `TryPlay`，可设置层号和起始进度。

战斗、回放或预览工具可自行计算进度：

```csharp
bool sampled = playback.TrySample("Base Layer.Attack", elapsedTicks / (float)durationTicks);
```

`TrySample` 把该层切换为外部时间模式，后续 `Advance` 不推进该层。暂停本地播放器也不阻止显式采样，便于暂停时定位；冻结外部时间时，调用方保持进度不变。`TryPlay` 可把该层切回本地时间模式。

## 状态、结束和所有权

- `TryGetState(layer, out state)` 返回 `AnimationPlaybackState`：状态名、进度、速度、循环、外部时间、完成标记。非循环到达 1 后保持最后姿态；循环进度回绕。
- `Stop()` 清除所有层的播放跟踪并保留姿态；`Reset()` 清除跟踪与暂停，重新绑定控制器的初始姿态。
- `Dispose()` 恢复创建前的 Animator 速度和剔除模式，不销毁 Animator、控制器或片段。模型回收、场景退出或窗口关闭时先释放播放器，再释放实例和资源租约。
- 一个 Animator 同时只交给一个播放器控制。不要同时从其他代码修改它的速度、状态或控制器；更换控制器后重建播放器并重新播放。
- 所有调用在 Unity 主线程执行。空对象、无控制器、缺失状态、非法层号、负数/非有限时间与速度通过 `false` 或无操作拒绝；调用方检查 `Try*` 的结果。

## 控制器约定

播放器通过 `Animator.Play` 和 `Animator.Update(0)` 显式采样，并关闭自动时间推进。适合由业务代码明确切换状态的控制器；首版采用无自动过渡的状态机。各层权重与遮罩沿用控制器设置，未提供 CrossFade、BlendTree 参数封装或动作队列。

通用层不修改 Root Motion 开关，调用方按用途配置；需要权威逻辑坐标的玩法应关闭 Root Motion。动画事件不能作为战斗伤害的权威来源。生命周期和玩法暂停由调用方管理，不隐式订阅全局暂停事件。

项目中的实际接入、热更目录与自动化验证见[角色动画与战斗接入](../project/角色动画与战斗接入.md)。
