# 框架文档

本目录维护通用框架的设计、使用指南、API 索引、模板复用流程及历史验收记录。ProjectExtraction 的当前业务开发与后续验收以 [v2 项目文档](../project/v2/README.md)为入口；旧资料归档规则见[项目版本导航](../project/README.md)。本目录中的模板示例和框架历史验收不代表 v2 玩法或平台已经完成。

- [AI 开发入口](AI开发入口.md)、[脚手架使用指南](AI开发脚手架使用指南.md)：从现有能力开始扩展。
- [API 索引](api/README.md)、[生命周期约定](api/生命周期约定.md)：查阅签名与所有权。
- [新项目复用](新项目复用.md)、[资源与依赖清单](新项目资源与依赖清单.md)、[统一验收](统一验收.md)：模板与检查流程。
- [通用动画播放](通用动画播放.md)：不依赖玩法的 Animator 播放、暂停和显式采样。
- [框架设计方案](Unity小游戏框架设计方案.md)：设计范围与演进背景。

API 索引由 Unity 的 **Refresh API Index** 生成到 `docs/framework/api`，修改公开 API 后运行 **Check API Index**。带日期的框架验收记录保留其历史语境，不能替代本项目实测。
