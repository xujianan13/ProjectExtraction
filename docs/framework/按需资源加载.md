# 按需资源加载

`GamePackage` 启动时默认准备 `Startup` 标签、`HotUpdateBootSettings.asset` 中 `additionalStartupDownloadTags` 指定的标签，以及 YooAsset 无标签公共依赖。`downloadAllResourcesBeforeLaunch` 设为 `true` 时，恢复启动前下载所有缺失资源；直接创建 `UpdatePackageRequest` 且 `DownloadTags == null` 也保持整包差量下载。初次采用按需模式须重建并发布带标签的内容版本；旧无标签包仍会全量下载。

## 构建和发布

`Prepare GamePackage` 将 `GameResources` 的 `Code`、`Config`、`Input`、`Startup` 直接子目录标为 `Startup`（不存在则跳过）。其他直接子目录获得目录名与 `Optional` 标签，并按资产分别打包；`Code`、`Config` 按目录打包。收集器仍使用 `AddressByFileName`。`GamePackageBuildSettings.asset` 的 `Additional Startup Directories` 可添加其他直接子目录。包级配置、热更 DLL、AOT 元数据、必需地址和非空的首场景地址均须在启动分组中；若位于其他目录，所属目录自动获得 `Startup` 标签。与用户收集器重叠时 Prepare 会报错。

| 菜单命令 | 内容输出 | 安装包内置资源 |
| --- | --- | --- |
| `Build Startup GamePackage` | 完整内容包，供 CDN 发布 | 清空后只复制 `Startup` 标签及其依赖 |
| `Build Offline GamePackage` | 完整内容包 | 清空后复制全部 |
| `Build Remote GamePackage` | 完整内容包，供 CDN 发布 | 不替换现有首包 |

Startup 首包仍需配置 CDN，并发布同版本完整内容输出，才能在使用时取得未内置的资源。版本文件、Manifest、Bundle 和 `GamePackage_<version>.settings.json` 须一起发布；构建不覆盖已有版本。

## 下载与内存预加载

Boot 已为 `GamePackage` 配置落盘预下载。自行初始化其他资源包时，激活后调用 `resources.ConfigureDownloadSupport(packageName, supported)` 明确声明能力。默认 Web 模式不支持落盘预下载，`DownloadAsync` 返回 `Unsupported`；Web 仍可按需加载对象，但不能因此视为离线就绪。

```csharp
IResourceModule resources = GameEntry.Get<IResourceModule>();
ResourceDownloadResult result = await resources.DownloadAsync(
    ResourceDownloadRequest.ForLocations(new[] { "HeroPrefab" }), ct: ct);
```

按标签预下载时使用 `ResourceDownloadRequest.ForTags(new[] { "Characters" })`；`ForLocations` 与 `ForTags` 二选一。`DownloadAsync` 将 Bundle 及依赖写入缓存，不加载 Unity 对象；`Status` 区分成功、失败、取消和不支持，成功时 `TotalCount == 0` 表示文件已在本地。`CanRetry` 表示底层下载失败后是否值得重试。

`AcquireGroupAsync` 可跨平台将一组资源加载到内存，返回由业务持有的 `ResourceGroupLease`。资源不再使用时调用 `Dispose()`：

```csharp
var group = new ResourceGroupDefinition("Level", new[]
{
    new ResourceGroupDefinition.Item("hero", "HeroPrefab", ResourceGroupDefinition.AssetKind.GameObject)
});
ResourceGroupLease lease = await resources.AcquireGroupAsync(group, ct: ct);
try
{
    lease.TryGet("hero", out UnityEngine.GameObject hero);
}
finally
{
    lease.Dispose();
}
```

## UI 与 PrefabPool

`OpenWindowAsync` 默认在等待 150 毫秒后显示等待层；`UILoadOptions.BusyDelayMilliseconds` 可调整。可恢复的资源失败会提示重试或取消，取消抛出 `OperationCanceledException`。`RunWithLoadingAsync` 可包裹其他异步资源操作：

```csharp
IPrefabPoolModule pools = GameEntry.Get<IPrefabPoolModule>();
IUIModule ui = GameEntry.Get<IUIModule>();
PrefabPool pool = await ui.RunWithLoadingAsync(token =>
    pools.CreatePoolAsync("HeroPrefab", ct: token), ct: ct);
```

传给 `RunWithLoadingAsync` 的操作必须协作响应传入的取消令牌，并自行处理取消后到达的结果，避免业务失去结果所有权。`PrefabPool` 由创建它的业务保存，在场景退出时调用 `DisposeAsync()`。
