# 音频系统

IAudioModule 经 Resource 模块按 Address 异步加载 AudioClip，使用 Music、Sfx、Voice 三个通道播放。将业务音频放入 DevProject/Assets/GameResources/Audio，由 GamePackage 的现有构建与更新流程管理。框架管理音源和片段租约；业务管理收听者、Mixer 资产及播放生命周期。

## 播放与定位

原有 PlayAsync(address, channel, loop: false, ct: default) 保持 2D 行为。新增 AudioPlayOptions 重载默认也为 2D。音频 API 应在 Unity 主线程调用。

~~~csharp
var audio = GameEntry.Get<IAudioModule>();
var music = await audio.PlayAsync("Audio/Bgm", AudioChannel.Music, loop: true, ct: ct);
var hit = await audio.PlayAsync("Audio/Hit", AudioChannel.Sfx, new AudioPlayOptions { Volume = 0.8f }, ct);
var impact = await audio.PlayAtAsync("Audio/Impact", hitPoint, AudioChannel.Sfx, ct: ct);
var engine = await audio.PlayFollowAsync("Audio/Engine", vehicleTransform, AudioChannel.Sfx,
    new AudioPlayOptions { Loop = true, FollowOffset = new Vector3(0f, 0f, -1f) }, ct);
~~~

PlayAtAsync 使用世界坐标固定位置，PlayFollowAsync 跟随 Transform。两者均强制 3D。FollowOffset 是目标本地坐标偏移，使用 Transform.TransformPoint 换算。直接调用新 PlayAsync 重载时，可通过 SpatialBlend = 1f 和 Position 或 FollowTarget 配置 3D；SpatialBlend = 0f 为 2D。相机或玩家应只保留一个启用的 AudioListener。

## AudioPlayOptions

| 属性 | 默认值与作用 |
| --- | --- |
| Loop | false；循环播放需显式停止或交给 Owner。 |
| Volume、Pitch | 均为 1；Pitch 限制为 0.01～3。最终响度还受主音量、通道音量和 Mixer 影响。 |
| SpatialBlend、Position | 默认 0（2D）和世界坐标原点。 |
| FollowTarget、FollowOffset | 可选目标及本地坐标偏移。StopWhenTargetDestroyed 默认 true，目标销毁时停止；设为 false 则留在最后位置继续播放。 |
| MinDistance、MaxDistance、RolloffMode | 默认 1、50、AudioRolloffMode.Logarithmic，控制 3D 衰减。 |
| CustomRolloff | 自定义音量衰减 AnimationCurve；横轴为归一化距离 0～1，配合自定义 RolloffMode 使用。 |
| DopplerLevel、Spread、Priority | 默认 1、0、128，对应 Unity AudioSource 参数。 |
| OutputGroup | 可选 AudioMixerGroup；为空时使用通道默认路由。 |
| FadeInSeconds | 默认 0；按不受 Time.timeScale 影响的时间从静音渐入至 Volume。 |
| Owner | 可选 LifetimeScope；作用域停止或释放时清理加载中及已播放音频。 |

调用方 CancellationToken 只取消本次加载，取消时抛出 OperationCanceledException；播放开始后用句柄、通道或 Owner 停止。加载失败、加载期间被停止或抢占时返回无效句柄，可检查 handle.IsValid。短音频自然播完会释放音源与片段租约，并解除作用域登记。

## 作用域与控制

场景、窗口每轮打开、池对象每轮生成分别使用 SceneScope、OpenScope、SpawnScope。作用域扩展将播放归本轮所有，作用域停止会终止加载中或播放中的音频。

~~~csharp
var audio = GameEntry.Get<IAudioModule>();
var scope = SceneScope;
var handle = await scope.PlayAudioAsync(audio, "Audio/Ambience", AudioChannel.Sfx,
    new AudioPlayOptions { Loop = true }, ct);
if (!scope.IsActive || !handle.IsValid) return;
~~~

IsPlaying(handle) 在暂停期间仍为 true，表示句柄仍占用音源。Stop(handle) 立即停止；Stop(handle, fadeOutSeconds) 淡出后停止。FadeTo(handle, volume, duration, stopWhenComplete: false) 将该音频的单音量渐变至 0～1 的目标值。淡变采用不受时间缩放影响的时间；PauseAll、应用后台暂停或 AudioListener.pause 时，淡变和自然结束回收冻结。StopChannel、StopAll 可批量停止。

背景音乐可先等待新曲加载成功，再让旧曲淡出；加载失败时保留旧曲：

~~~csharp
var next = await audio.PlayAsync("Audio/NextBgm", AudioChannel.Music,
    new AudioPlayOptions { Loop = true, FadeInSeconds = 0.5f, Owner = SceneScope }, ct);
if (next.IsValid) audio.Stop(previousMusic, 0.5f);
~~~

## 并发上限

Music、Sfx、Voice 默认上限分别为 2、32、8，加载中也占用名额。GetActiveCount(channel) 返回占用数；GetVoiceLimit(channel) 返回上限。SetVoiceLimit(channel, maxVoices, policy) 配置上限和溢出策略；默认 AudioVoiceOverflowPolicy.StealOldest 抢占最早播放，RejectNew 拒绝新播放并返回无效句柄。

~~~csharp
audio.SetVoiceLimit(AudioChannel.Sfx, 24, AudioVoiceOverflowPolicy.RejectNew);
var active = audio.GetActiveCount(AudioChannel.Sfx);
~~~

## Mixer 路由与租约

业务可创建 AudioMixer 资产并放在 GameResources/Audio；框架不生成默认 Mixer 资产。GetChannelMixerGroup、SetChannelMixerGroup 管理通道默认路由，单次播放的 OutputGroup 可覆盖它。作用域 AcquireAsync<AudioMixer> 取得 Mixer 时，应在租约释放前先停止引用相关 Group 的音频，再清除路由：

~~~csharp
var scope = SceneScope;
var resources = GameEntry.Get<IResourceModule>();
var mixerLease = await scope.AcquireAsync<AudioMixer>(resources, "Audio/GameMixer", ct: ct);
if (!scope.IsActive) return;
var groups = mixerLease.Asset.FindMatchingGroups("Master/Music");
if (groups.Length == 0) return;
audio.SetChannelMixerGroup(AudioChannel.Music, groups[0]);
scope.Defer(() =>
{
    audio.StopChannel(AudioChannel.Music);
    audio.SetChannelMixerGroup(AudioChannel.Music, null);
});
~~~

清理登记位于 Mixer 租约之后，作用域逆序释放时会先停止音频、清除路由，再释放 Mixer。Mixer Address 与 Group 路径以业务资产为准。若单次播放设置 OutputGroup，释放其 Mixer 租约前也须先停止对应句柄。片段租约释放后，由资源模块按现有缓存规则处理资产和 Bundle。

## 实现依据

自然回收读取音源实际播放状态，兼容变调和多普勒引起的时长变化。暂停期间跳过回收，因为 Unity 的 [AudioSource.isPlaying](https://docs.unity3d.com/2022.3/Documentation/ScriptReference/AudioSource-isPlaying.html) 在调用 Pause 后返回 false。框架暂停与 [AudioListener.pause](https://docs.unity3d.com/2022.3/Documentation/ScriptReference/AudioListener-pause.html) 也会冻结淡变进度。

## 平台验收

浏览器声音启动可能需要用户手势。WebGL 与小游戏平台的实际声音、后台恢复和性能需在目标设备验收；本文不代表这些平台已测。
