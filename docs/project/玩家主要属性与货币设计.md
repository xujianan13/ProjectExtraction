# 玩家主要属性与货币设计

更新日期：2026-09-29。状态：设计草案，尚未实现。已确认规则以[核心玩法设计](核心玩法设计.md)为准，模块分工见[玩法模块与迭代计划](玩法模块与迭代计划.md)。

## 1. 五项主要属性

等级、经验、体力、金币、钻石构成玩家主要属性，用于局外成长、出战节奏与资源消费。生命值、攻击力、攻击范围等仍属于战斗属性，由战斗和物品模块管理。

| 属性 | 已确认定位与规则 | 建议数据口径 | 权威模块 |
| --- | --- | --- | --- |
| 等级 | 经验达到门槛自动升级；控制高级装备穿戴、关卡解锁、局外购买，并按配置发放技能点 | 根据有效经验和升级曲线推算，不允许 UI 单独修改等级 | M07 |
| 经验 | 打怪与成功撤离均产生经验 | 建议保存累计经验，当前等级进度由曲线推导；来源分别记录和去重 | M07 |
| 体力 | 控制出战节奏；暂定上限 100，每局 10，每 6 分钟恢复 1 | 保存当前值、时间基准、扣费与领取记录 | M09 |
| 金币 | 常规货币，用于购买物品等常规消耗；出售战利品可获得金币 | 建议保存非负整数余额，收支记录包含来源和交易标识 | M07 |
| 钻石 | 独立的高级货币体系，具体消费项目待定 | 建议保存独立的非负整数余额；来源和具体消费项目待定 | M07 |

技能点与已学技能等级归 M07 的局外成长状态，不是第六项顶部主要属性，也不是金币/钻石之外的交易货币。技能点在技能面板显示并用于局外提升角色技能，具体规则见[技能成长设计](技能成长设计.md)。

等级和经验是同一成长状态的两个表现，不能各自保存后独立变化。建议以累计经验及曲线为计算依据；若保存等级缓存，加载与更新时须校验一致性。经验计算口径、满级规则及初始值后续配置，不在本轮补入固定初始等级或金币、钻石赠送数量。

体力最新规则为每天 **05:00 重置到 100 点**，**12:00、18:00、24:00 各可手动领取 40 点**；24:00 即次日 00:00。领取溢出、窗口及离线恢复仍按[M09](模块设计/M09-体力与每日补给.md)的待定事项处理，体力重置不能顺带重置其他主要属性。

## 2. 金币与钻石的经济定位

| 货币 | 当前确认的获得途径 | 当前确认的用途 | 尚未确认的内容 |
| --- | --- | --- | --- |
| 金币 | 出售战利品 | 购买物品、其他常规消耗 | 出售地点和价格、其他获得途径、具体常规消耗项目 |
| 钻石 | 暂未指定 | 高级货币定位，具体消费项目待定 | 发放来源、高级商品或服务、价格与开放条件 |

- 金币负责常规消费，钻石负责单独定义的高级消费。两种货币各自配置产出、消费项目和价格。
- 商品或消费项目明确使用金币或钻石，报价包含固定币种、单价、数量和总价；交易只校验对应余额，余额不足则该笔交易失败。
- 金币与钻石独立记账，没有面值换算、高低币阶或余额补足关系。
- 本轮不把打怪和成功撤离扩展为直接奖励金币或钻石的来源：打怪经验、掉落物品、出售获得金币是不同过程。
- 钻石作为高级货币不自动引入充值、广告、签到、复活或购买体力等规则；这些需要后续单独设计。

## 3. 玩家账户与局内物品的边界

**建议将金币、钻石建模为局外账户余额**，由 M07 统一持有，供主要属性展示和交易使用。账户余额不复制成 M06 的背包物品数量；以后若设计可拾取的钱袋等物品，它们先是 M06 物品，兑换成余额时另走一次受控交易。

原有“死亡丢失安全箱外物品”的规则不能直接套到金币、钻石余额。建议已经确认入账的局外余额不因角色死亡而扣除；该死亡保留政策、局内临时货币及 NPC 房能否使用局外余额仍需确认。它们不因本轮新增两个主要属性而自动成为既定规则。

建议首版以“撤离/安全箱保留物品进入局外仓库 → 玩家选择出售 → 获得金币 → 购买物品”为经济闭环。出售动作不绑定撤离自动执行，成功撤离仍然保留全部当前持有物品。

局内 NPC 出售战利品、局内金币立即进入局外账户等功能会影响死亡损失，须先明确货币去留和商店资金范围，再接入；不能借一个未确认的出售入口把箱外战利品变成自动保留收益。

## 4. 购买与出售

### 购买

1. M07 按商店上下文提供有效报价，包含物品、币种、单价、数量限制、等级要求和报价版本。
2. M07 校验余额、适用的等级门槛与报价；M06 校验商品库存、接收容器和物品生成/转移条件。
3. 将“扣除报价指定货币 + 交付物品 + 交易完成标识”作为一次项目存档变化提交。
4. 保存确认后显示购买成功；余额不足、容器拒收、报价过期或保存失败均不能留下仅扣款或仅发货的结果。

### 出售

1. 玩家选择实际持有的战利品实例及数量；M07 根据最终可售规则和价格配置提供金币报价，M06 校验所有权、位置、数量及是否被其他操作占用。
2. 建议按具体实例展示属性和售价，避免同名随机装备被误当作同一件物品。批量出售和售出后的回购不属于当前已确认功能。
3. 已装配装备如何处理尚待定；首版建议拒绝直接出售并提示先卸下。不能因为出售而隐式更换武器。角色技能不是物品，不能出售。
4. 将“移出售出实例或减少所售堆叠数量 + 增加金币 + 交易完成标识”合并提交。堆叠规则未定，只有允许堆叠的物品才支持部分数量出售。
5. 保存确认后，玩家不再拥有售出数量，相应金币只增加一次。物品后续是否进入商店库存、能否回购另定，不能直接推导。
6. 不可出售、物品已转移、数量不符或报价失效时整笔拒绝；不得先删除物品再尝试加金币。

## 5. 数据契约与存档

以下为拟议名称，不代表现有 API；首版直接放在项目层，无需再新增一个业务模块。

| 契约 | 建议内容与约束 |
| --- | --- |
| `PlayerMajorAttributesView` | 等级、经验进度、体力与恢复状态、金币、钻石的只读聚合；M07/M09 提供权威状态，M08 展示 |
| `WalletState` | `Gold`、`Diamonds` 两项余额；建议使用容量足够的整数类型，校验负值和溢出，不使用浮点数计价 |
| `CurrencyAmount` | 明确币种与整数金额；体力和经验不是该货币枚举的支付选项 |
| `TransactionId` | 在当前玩家存档内唯一的交易标识，用于购买、出售及未来明确的货币发放去重 |
| `TransactionKind` | 购买、出售、发放等已配置操作类型，防止同一标识被解释为不同操作 |
| `ShopContextId` | 区分局外与 NPC 房商店；局外交易无需 RunId，NPC 房可附带 RunId 校验 |
| `TradeQuote` | 报价版本、方向、物品/实例、数量、币种、单价与总价；计算总价时校验溢出 |

原文档中的购买专用 `PurchaseId` 统一扩展为 `TransactionId`；目前无相关实现，不涉及代码或已发布存档迁移。

交易重试必须复用同一 TransactionId，并核对操作内容一致；相同标识更换币种、数量或物品应拒绝。保存结果不确定时先收束同一提交，不能换一个 ID 再扣款或卖出。物品、钱包和交易标识必须一起持久化。

等级、经验、已学技能等级、剩余技能点、体力和钱包都通过统一项目存档入口串行合并更新。技能点只随已确认生效等级逐级发放并去重；已保存技能状态不随死亡物品损失清除。M01 结算不能拿旧快照覆盖局外已完成的金币交易、钻石变化或体力补给；M09 的 5 点重置只更新体力相关状态。

## 6. UI 与反馈

- 局外主界面顶部展示等级、经验进度、体力、金币和钻石，底部提供仓库与技能两个入口；技能点在技能面板展示。布局见[主界面设计](主界面设计.md)。属性变化读取业务结果，按钮点击不等于收支已完成。
- 商品显示明确币种图标和数值；出售明确展示物品、数量及将获得的金币，余额不足提示缺少哪种货币及差额。
- 等级只展示升级进度和资格，经验自动升级；不把金币、钻石余额混入等级或战斗属性计算。
- 装备穿戴、关卡准入、局外购买三类等级门槛分别展示；技能提升按技能点和升级条件校验。低等级持有装备不自动禁止出售。
- 钻石来源和消费尚未定义时可显示余额，不添加未确认的充值、兑换或购买体力按钮。

## 7. 建议迭代与验收

保持 M01～M09 模块编号：M07 增加双币钱包与买卖，M06 接物品交付，M08 接五项属性展示。I2 可先接只读属性视图；I4 接入金币买卖闭环和双币报价校验；钻石实际商品与发放按后续规则接入。

未来验收重点：

1. 增加经验后等级和进度一致；体力恢复/5 点重置不会改变金币、钻石、等级或经验。
2. 金币消费只校验并扣除金币，钻石高级消费只校验并扣除钻石；对应余额不足时交易失败，物品和两项余额均保持原状态。
3. 出售一个实际持有的随机装备后，恰好移出该实例并增加一次报价金币；相同交易重试不重复收入。
4. 出售失败、保存失败、并发转移或库存不足时不出现丢物未加币、加币未移物或负余额。
5. 正常撤离不自动售卖物品，死亡结算不凭物品去留规则清空账户余额；完整死亡处理待货币政策确认后验收。
6. 交易完成后重开存档，余额、实例归属和交易标识一致；取消、连续点击、重复回调不造成多次买卖。

## 8. 尚需确定

- 金币与钻石的初始余额、余额上限；金币出售以外的来源；钻石来源及具体高级用途。
- 出售入口、可售战利品类别、已装配装备处理、价格公式与随机属性对价格的影响。角色技能不进入可售物品范围。
- NPC 房使用何种币、是否直接使用局外余额，是否支持出售，是否与局外共用商品和库存。
- 账户余额死亡政策、局内临时货币与结算关系；异常中断时未完成交易的恢复方式。
- 常规消费的金币定价、高级消费的钻石定价和各自等级要求；出售是否支持回购另行决定。
