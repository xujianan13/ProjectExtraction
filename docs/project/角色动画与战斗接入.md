# 角色动画与战斗接入

## 当前实现

采用“通用播放器 + 玩法适配器”。框架的 `AnimatorPlayback` 可直接用于局外角色、NPC 和其他需要 Animator 的对象；`CombatCharacterAnimation` 负责把 ECS 快照映射为本项目的动作。使用方法见[通用动画播放](../framework/通用动画播放.md)。

```text
局外展示 / NPC / 其他场景 ───────────────┐
                                       ↓
ECS → CombatAnimationSnapshot → 战斗适配器 → AnimatorPlayback → Animator / 动画片段
```

角色移动、朝向依据和命中事实来自 ECS。片段只改变 `Mesh` 子节点的局部位置、旋转和缩放；角色根节点位置仍由 ECS 快照确定，关闭 Root Motion，片段不带 AnimationEvent。

## 状态与时间

当前控制器为单层 `Base Layer`，包含以下状态，无自动过渡：

| 优先级 | 状态 | 触发与进度 |
| --- | --- | --- |
| 1 | Death | 死亡事实，36 个战斗帧倒下，结束后隐藏敌人模型 |
| 2 | Hit | 正伤害后的 11 帧受击反馈；闪避与零伤害不触发 |
| 3 | Attack | Cue 编号 1 / 20 / 30，按配置持续帧数采样 |
| 4 | Move | 当帧实际位移速度不为零，0.6 秒循环 |
| 5 | Idle | 无上述状态，1 秒循环 |

攻击 Cue 持续帧数当前为玩家 16、普通敌人 38、Boss 48。Cue 保存施放方向；战斗快照也包含实际移动速度、角色时钟、受击与死亡经过帧数。受击动画覆盖攻击表现，但不会改变技能时间轴和伤害执行。

- 玩家动画使用世界时钟；敌人使用所在房间的时钟。离开房间后敌人的技能、受击和死亡进度冻结，回访继续。
- 三选一、手动暂停和应用后台通过既有单局暂停停止 ECS 时钟；重复采样同一快照不会推进动作。当前房间 NPC 的待机也通过通用播放器同步采样。
- 切换房间取消玩家未完成动作，清理旧挥击提示；死亡或取消施法会清理对应提示。挥击线条当前是一次性提示，回访时不会重建旧线条，角色动作仍按快照恢复。
- 玩家死亡立即停止 ECS 并冻结、持久化终局，原场景继续显示 0.6 秒倒下与 0.15 秒停留，然后进入结果页；表现时钟不产生伤害或奖励，后台暂停时冻结。敌人的倒下表现仍按房间时钟播放。详见[战斗反馈与角色碰撞](战斗反馈与角色碰撞.md)。

## 热更资源

```text
Assets/GameResources/Art/Prototype/Animations/
├─ Clips/
│  ├─ AN_TestIdle.anim
│  ├─ AN_TestMove.anim
│  ├─ AN_TestAttack.anim
│  ├─ AN_TestHit.anim
│  └─ AN_TestDeath.anim
└─ Controllers/AC_TestCharacter.controller
```

五个动作仍为胶囊体测试表现。玩家、普通敌人、Boss 与 NPC 的 Prefab 根节点挂 Unity 原生 Animator，共用此控制器，不挂载 GameLogic MonoBehaviour。NPC 首版仅使用待机。正式模型接入时可替换 Controller / OverrideController 和片段，保持适配器中的状态约定；需要不同动作语义时扩展项目适配器。

14 个基础关卡 Prefab 继续通过 `ExpeditionVisualAssets` 加载，新增反馈资源由 `CombatFeedbackAssets` 另行获取。控制器、片段作为 GamePackage 的 Art 资源及 Prefab 依赖进入热更包，随场景租约管理；加载时检查四个角色的 Animator 与控制器。先释放动画控制权，再销毁实例、释放资源。

## 编辑与生成

菜单 **Tools → ProjectExtraction → Create Character Animations** 对应 `ProjectCharacterAnimationBuilder.CreateMissing`。**Create Test Prefabs** 也会补齐动画资源。

生成器只创建缺失的片段和控制器，为四个测试角色补齐 Animator。已有片段、控制器和人工替换的其他控制器会保留；使用标准控制器的测试 Prefab 会校正 Root Motion、剔除和速度配置。修改源码或资源后执行 **Prepare GamePackage**；资源版本按现有构建规则递增。
