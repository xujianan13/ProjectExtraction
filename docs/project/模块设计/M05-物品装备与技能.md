## 定位与已确认规则

M05 负责物品定义、装备实例随机值、装备属性汇总，以及角色技能和武器附加效果的静态配置与纯数值计算。ECS 运行实例和改变战斗世界的效果执行器归 M03。角色技能通过等级成长取得技能点，在局外消耗技能点提升；它不是装备或物品。

- 仅有近战武器，所有武器共用一种基础攻击方式。
- 武器差异仍可来自攻击范围等属性、随机数值和原“附带技能”。为避免与角色技能混淆，后者统一称为**武器附加效果**；其保留、触发和与角色技能叠加的具体规则待定，不删除武器差异。
- 高级装备穿戴受角色等级约束；门槛由装备配置提供，M07 判断资格，M06 执行装配。门槛不自动限制拾取、持有和正常携出。
- 角色技能没有物品实例、掉落、携出或装配资格；技能点和已升级的技能等级是局外成长状态，由 M07 持有并保存。
- 物品正常撤离全部带回、死亡时安全箱内保留的规则由 M01、M06 执行，不适用于角色技能成长记录。

## 本轮属性与装备补充

- 角色战斗属性为 HP、攻击、防御、暴击值、暴击伤害、闪避、增伤、减伤。武器与护甲使用统一属性数据。
- 品质依次为普通/精良/优秀/史诗/传说/神器，对应白/绿/蓝/紫/橙/红。装备有默认属性，高品质增加额外随机词条。
- 实例保留随机结果；高级条件增伤、技能参数修改与触发效果通过后续词条定义扩展，具体规则见[专项设计](../角色属性与装备词条.md)。

## 职责与边界

1. 定义装备及其他可携物品的类别、静态配置、实例身份、随机属性与生成参数。
2. 由掉落、商店等来源请求生成物品实例，保证同一实例的随机值稳定可追溯。
3. 根据 M06 的已装配物品计算有效属性，并供 M02、M03 使用。
4. 定义 `SkillDefinition`：角色技能身份、各等级效果，以及在规则确定后配置升级成本、等级上限、前置条件等。向 M07 提供配置查询，依据 M07 提供的已保存技能等级计算效果；不持有技能点余额或写入技能等级。
5. 定义 CombatSkillDefinition、ProjectileDefinition、BuffDefinition、EffectDefinition 及武器附加效果，提供参数与引用校验；生命周期、命中和效果队列由 M03 执行。具体武器词条与技能搭配另定，通用时序和 Buff 合并按战斗设计。
6. 向 M08 提供物品、角色技能与武器附加效果的名称、描述及效果展示数据。
7. M06 管物品存放位置、容量、转移及装配；M01/M06 管单局携出和死亡物品损失。M05 不据此增删技能成长记录。
8. M07 独占已确认等级、技能点授予和消费、`SkillProgressionState` 与局外技能升级事务。M05 仅提供技能定义、成本等配置和效果计算，不能以装备接口绕过 M07。
9. M05 向 M07 提供物品分类、实例属性等买卖所需描述，不持有金币或钻石，不因报价删除物品或重抽随机值。

## 数据边界与依赖

| 数据 | 权威归属 | 使用方式 |
| --- | --- | --- |
| `ItemInstanceId`、随机属性、装备要求 | M05 定义，M06 管实例归属与位置 | 只用于物品和装备；角色技能没有 `ItemInstanceId` |
| `SkillDefinition` / `SkillId`、升级成本、各等级映射 | M05 | 局外成长配置；M07 查询等级和成本，M05 据已保存等级评估参数 |
| `CombatSkillDefinition` / `CombatSkillId` | M05 | 战斗时间轴和施法配置；可被成长技能映射，普通攻击和敌人攻击无需成长 SkillId |
| Projectile/Buff/Effect 定义及属性规则 | M05 | 只定义配置、纯数值与参数；Cast/Projectile/Buff 实例、效果上下文和修改世界由 M03 持有 |
| `SkillProgressionState`（各技能等级、可用技能点） | M07 | M08 读取展示；M05 只读生效等级 |
| 角色等级和技能点授予、消费 | M07 | M06 查询装备穿戴资格；局外升级由 M07 提交 |
| 钱包与买卖交易 | M07；物品位置由 M06 | 技能不是商品或出售对象；两种货币按各自报价独立消费 |

共享物品标识候选为 `ItemInstanceId`、`SourceId`、`RunId`、`ActorId`。角色技能另用稳定的 `SkillId` 定义身份，不生成物品实例。这些接口名均为拟议契约，尚非已有 API。

## 最小实现切片

### 切片 1：物品定义与实例

- 配置两件基础攻击一致、属性不同的近战武器；其中一件可携带待定的武器附加效果。
- 从确定的配置与生成参数得到装备实例，记录身份和随机属性值。
- 同一装备实例在房间切换、背包转移和结算中不重新抽取随机值。

### 切片 2：装备属性闭环

- M06 提供已装配实例，M05 计算攻击范围等有效属性。
- M02 和 M03 使用同一份属性结果；更换装备后重新计算，M05 不搬动物品。

### 切片 3：角色技能与武器效果

- 配置至少一个角色技能定义，以 M07 的已保存技能等级驱动效果计算和 M08 展示；升级动作仅由 M07 在局外执行。
- 用一件有武器附加效果的武器验证参数评估与统一基础攻击兼容，交给 M03 的效果执行器实际触发。
- 触发入口先按测试上下文驱动，不提前确定主动、自动或被动形式。

## 可操作验收标准

1. 同一装备实例读取、转移和重新装配后，`ItemInstanceId` 与随机值不变。
2. 两件武器共用基础攻击，攻击范围等差异可被 M02、M03 读取。
3. 角色技能按 M07 保存的等级产生效果；它不出现在 M06 背包、安全箱、掉落、出售、购买和装备槽中，不参与死亡物品损失。
4. M06 改变装配关系后，装备属性重新计算；M05 不改变容器位置。
5. 相同配置版本、技能等级、装备和计算输入产生一致参数；M03 依据触发身份执行和去重。武器附加效果有独立来源，M05 纯计算不修改生命、实例或技能点。
6. 等级不足时高级装备穿戴失败且物品状态不变；不因等级不足删除或禁止携出已持有装备。

## 决策待定

- 物品配置字段、随机数值区间、分布、生成时机与高级装备等级门槛。
- 技能列表、每级技能点授予数量、各技能升级成本、等级上限与前置条件。
- 角色技能的主动、自动或被动触发方式；是否存在重置或洗点。
- 武器附加效果的具体保留形式、触发条件，以及与角色技能的优先级、叠加和冷却规则。
