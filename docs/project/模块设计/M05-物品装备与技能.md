# M05 物品装备与技能

更新日期：2026-09-29。状态：模块设计草案，尚未实现，配置结构与技能使用方式尚未锁定。

关联：[核心玩法设计](../核心玩法设计.md) · [玩法模块与迭代计划](../玩法模块与迭代计划.md)

## 定位与已确认规则

M05 唯一负责物品定义、物品实例随机值、属性汇总与技能效果生效计算。

- 战利品包括装备、技能等物品；技能是可以带出关卡的特殊物品。
- 仅有近战武器，所有武器共用一种基础攻击方式。
- 武器差异来自攻击范围等属性、随机数值和附带技能。
- 高级装备穿戴与技能装配受角色等级约束，门槛由物品配置提供；未达到门槛不自动限制拾取、持有和正常携出。
- 随机区间、生成时机、技能持有与使用方式尚未确定。
- 正常撤离全部带回，死亡保留安全箱内物品；该规则由 M01、M06 执行。

## 职责与边界

1. 定义物品类别、静态配置、实例身份、随机属性与生成参数。
2. 由掉落、商店等来源请求生成物品实例，保证同一实例的随机值稳定可追溯。
3. 根据已装配物品计算角色的有效属性，提供给 M02、M03 使用。
4. 定义技能物品及武器附带技能的效果，统一计算触发后对属性或战斗结果的影响。
5. 向 M08 提供物品名称、描述、属性和技能效果的展示数据。
6. 不决定物品存放位置、容器容量、物品转移或掉落领取；这些归 M06。
7. 不根据单局结束直接删除物品或清空技能；携出和死亡损失归 M01、M06。
8. 不增加武器专属基础攻击操作；技能差异在属性或效果层表达。
9. 定义装备和技能的所需角色等级，由 M07 提供角色等级与资格查询、M06 在装配前校验；不能只在 UI 隐藏入口或在 M05 另存一份等级。

## 输入、输出与依赖

| 方向 | 内容 | 来源或去向 |
| --- | --- | --- |
| 输入 | 物品生成来源、关卡等级及生成参数 | M03/M04/M07 提供上下文，M06 统一去重后请求 |
| 输入 | 已装配物品实例与使用状态 | M06 |
| 输入 | 战斗命中、受击及其他触发上下文 | M03 |
| 输出 | 有唯一身份和稳定随机值的物品实例 | M06；商店等调用方读取其受控视图 |
| 输出 | 有效角色属性、攻击属性与技能效果结果 | M02、M03 |
| 输出 | 物品展示数据、所需角色等级 | M08 展示；M06/M07 校验装配资格 |

共享标识候选为 `ItemInstanceId`、`SourceId`、`RunId`、`ActorId`。
标识类型和接口形式为拟定契约，待第一批物品实例落地后锁定。

## 最小实现切片

### 切片 1：物品定义与实例

- 配置一件基础近战武器、一件属性不同的近战武器和一件技能物品。
- 从确定的配置与生成参数得到实例，并记录物品身份及随机属性值。
- 同一实例在房间切换、背包转移和结算中不重新抽取随机值。

### 切片 2：装备属性闭环

- 由 M06 提供已装配实例，M05 计算攻击范围等有效属性。
- M02 和 M03 消费同一份属性结果，保证显示与战斗判定一致。
- 更换装备后重新计算；不在 M05 中搬动物品。

### 切片 3：技能效果闭环

- 用一件可携出的技能物品验证效果计算和展示数据。
- 触发方式先以测试入口驱动，避免把主动、自动或被动形式提前定为规则。
- 用一件附带技能的武器验证其效果与统一基础攻击兼容。

## 后续扩展

- 待配置确定后加入品质、更多随机属性、数值分布和生成权重。
- 待技能规则确定后扩展触发条件、冷却与效果叠加。
- 将物品配置放入项目既有导表链路，避免把项目规则写入通用框架。

## 可操作验收标准

1. 同一物品实例在读取、转移和重新装配后，`ItemInstanceId` 与随机值保持不变。
2. 两件武器共用基础攻击逻辑，攻击范围等属性变化由 M02、M03 读取到。
3. 技能物品能够以独立物品实例保存并展示，不因一次战斗或单局结束被 M05 清空。
4. M06 改变装配关系后，属性重新计算；M05 不改变容器位置。
5. 同一战斗上下文按统一顺序计算技能效果，可追踪其来源且不重复触发。
6. 等级不足时装备/技能装配失败且原状态不变；达到配置门槛后可装配。门槛不会自动删除或禁止携出已经持有的高级物品。
