# 战斗反馈与角色碰撞

> **v1 历史归档**：正文中的“当前”“已确认”和验收结果均指 v1 时期。当前开发采用 [v2](../v2/README.md)；本页不要求保留 v1 运行代码。

## 当前接入

本轮在原型 ECS 战斗上补齐反馈和占位规则。表现层读取战斗事件、角色状态与 `CombatWorld.GetTelegraphsSnapshot`；命中、伤害、施法时间轴和移动仍由 ECS 决定。关卡进入时通过 `CombatFeedbackAssets` 获取热更资源租约，`ExpeditionPresentation` 管理画面反馈，`CombatFeedbackAudio` 播放本局音效。资源失败沿现有场景入场回滚处理。

- 存活角色头顶的世界空间血条从角色 HP 快照更新；死亡或离开当前房间后移除。血条、飘字始终朝向相机。
- 已确认的 `Damage` 事件显示数字；暴击显示“暴击”及放大文字，闪避事件显示“闪避”。正伤害另触发短暂命中球和角色模型闪白，角色原有材质属性块随后恢复。飘字和命中特效使用有限池。
- 当前房间尚未执行的下一次伤害或飞弹发射节点形成地面预警，按圆、扇形、矩形或胶囊形状绘制。玩家为蓝色、敌人为红橙色，透明度随施法进度变化。取消、死亡、已经执行的节点不再输出；敌人跨图施法由房间时钟冻结，回访后继续。
- 挥击 Cue、普通正伤害、暴击分别播放 `SFX_CombatSwing`、`SFX_CombatHit`、`SFX_CombatCritical`。本局音效在暂停、换图和退出时停止；闪避没有单独音效。当前三个 WAV 是原创合成测试音效。

飞弹预警显示发射方向或出生目标范围：来源锚使用发射方向和配置范围，目标点快照锚与目标实体出生锚显示目标附近的圆；`SpawnOffset` 随施法方向旋转。这是发射提示，不表示飞弹之后的完整轨迹、转向或最终命中范围。地面预警目前也不按墙体做裁剪。

## ECS 占位与追击

角色在 XZ 平面按半径组成圆形占位；移动采用连续扫掠，接触房间边界、障碍或其他存活角色后沿切面滑动。墙体按角色半径扩大的保守矩形计算，角落可能比视觉网格更早阻挡。死亡角色不再阻挡通行。碰撞只存在于 ECS；胶囊体及反馈 Prefab 不承担物理碰撞。

同一占位检查覆盖普通移动、技能位移、角色出生与传送。切换房间先校验目标入口能占用，再原子更换房间与位置；失败不更换活动房间。敌人追击时，若直线被墙阻挡，就以障碍矩形扩半径后的角点选可通行路线；施法期间停止追击移动。当前没有 NavMesh，也没有动态拥挤避让或多人路径规划。

## 死亡与结果页

玩家死亡时立即停止 ECS、冻结本局结果，并先持久化不可变终局。原场景保留死亡表现时钟：约 0.6 秒倒下、0.15 秒停留，共 0.75 秒后进入结果页。表现期间不重新开放输入，不产生新伤害或奖励；后台暂停时停止计时，恢复时不追赶长帧。保存失败仍由现有恢复流程处理，不能以动画播放完成代替持久化成功。撤离结算不等待死亡表现。

## 热更资源

既有 14 个关卡测试 Prefab 保留。新增 `Gameplay/Expedition/Feedback` 下的 `PF_CombatHealthBar`、`PF_CombatDamageText`、`PF_CombatHit`、`PF_CombatTelegraph` 四个 Prefab；`Art/Prototype/Materials` 下的 `MAT_CombatHit`、`MAT_CombatTelegraph` 两个材质；`Audio/Combat` 下的 `SFX_CombatSwing`、`SFX_CombatHit`、`SFX_CombatCritical` 三个 WAV。资源生成器入口为 **Tools → ProjectExtraction → Create Combat Feedback**，只补齐缺失资产，不覆盖人工修改及 GUID。具体目录和租约见[测试资源与热更目录](测试资源与热更目录.md)。
