## 自动近战的遮挡候选

复查发现，原逻辑先从范围内选出最近敌人，再检查该敌人的视线。如果它在墙后，即使另一名稍远的敌人处于范围内且没有遮挡，玩家也不会攻击。

本轮将玩家的遮挡过滤放在候选选择阶段，从可见敌人中沿用既有距离规则选择目标。所有敌人都在墙后时不发起攻击；敌人的追击仍允许选择墙后的玩家，再沿现有路径绕障接近。已接纳的攻击继续沿用原时间轴、锁定方向和命中时的墙体检查。
