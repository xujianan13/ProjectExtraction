# 搜打撤交互首版实现

> **v1 历史归档**：正文中的“当前”“已确认”和验收结果均指 v1 时期。当前设计采用 [V3](../v3/README.md)；本页不要求保留或恢复 V1 运行代码。

本阶段接续[关卡内容首版实现](关卡内容首版实现.md)，完成局内换装、背包与安全箱、NPC 商品预览和购买。实现继续使用现有配置、ECS、uGUI 模态窗口与单局结算流程。

## 玩家操作

1. 点击战斗 HUD 的“背包 / 安全箱”，暂停模拟并清除摇杆与残留键盘交互。
2. 背包按单元格显示物品，可切换全部、武器、装备、物品；安全箱另有区域入口和容量显示。
3. 选择物品查看品质、等级要求、默认属性、额外词条，以及当前角色与穿戴或卸下后的属性对比。
4. 武器和护甲各占一个装备槽；穿戴新装备自动卸下同槽旧装备，旧装备留在背包。无武器时使用配置中的徒手攻击。
5. 已穿戴物品必须先卸下才能放入安全箱；安全箱内物品必须先移回背包才能穿戴。每件物品占一格。
6. 靠近 NPC 交互打开商店，浏览具体商品与价格，选择商品后点击“确认购买”。打开或关闭商店不扣金币。
7. 关闭模态窗口后继续探索；应用在后台或正在三选一时仍保持相应暂停。

## 换装与 ECS

- `ExpeditionRun.TryEquip` 在本局背包中查找真实物品，检查等级和安全箱状态，先向 ECS 提交属性，再一起提交同槽装备标记。
- `CombatWorld.TryReplaceBaseAttributes` 更换基础八属性、攻击范围和移动速度，保留局内永久强化、Buff、技能冷却和角色身份。
- 换装增加生命上限不会恢复当前生命；降低上限时将当前生命限制到新上限，不能通过反复穿脱回血。Roguelike 最大生命强化仍使用其原有独立规则。
- 装备属性与已接受的局内强化分别保存，暂时达到属性上限不会抹去先前强化。
- 玩家基础攻击的起手范围、伤害范围和预警使用新武器范围。已有施法和已发射飞弹保留触发时的进攻与范围快照；换装不重置冷却，也不更改敌人共享配置。
- 属性对比显示最终基础属性与局内永久强化；Buff 的独立移动和范围修正不计入这一装备对比。

## 商店规则

- 所有 NPC 房间在单局创建时，根据房间计划的 `NpcStock`、`NpcPrice`、`LootPoolID` 生成具体商品；按房间使用独立随机源。
- 每件商品具有稳定身份，品质、随机数值和词条在生成时冻结。查看、关闭、离开、回访都不会重新抽取。
- 一件商品只能购买一次，售出后继续显示“已售”；确认购买前检查当前房间、NPC 距离、暂停状态、库存和金币。
- 购买只消耗金币，余额不足就失败；不使用钻石补差。商品进入背包，不自动装备。
- 支出进入已有 `GoldSpent` 单局记录，在唯一终局保存中扣除；不新增另一条钱包保存流程。

## 暂停与生命周期

| 状态 | 可推进战斗 | 可操作背包或商店 |
| --- | --- | --- |
| 正常探索 | 是 | 先打开相应面板 |
| 背包或商店打开 | 否 | 当前面板允许 |
| 应用暂停或保存待恢复 | 否 | 否 |
| Roguelike 待选择 | 否 | 仅三选一 |
| 单局终止或场景退出 | 否 | 否，关闭相关窗口 |

`ActivePanel` 独立于应用暂停和 Roguelike 状态。关闭窗口只释放其拥有的面板状态；旧窗口回调不能解除其他原因导致的暂停。停止单局时清除面板状态，场景退出时关闭窗口并解除订阅。

## 携出与存档

- 正常撤离携出所有入场装备和战利品，包括已卸下装备、当前穿戴装备及 NPC 购买物品。
- 死亡仅保留安全箱内物品；安全箱外的入场装备、换上的装备及其他战利品全部丢失。
- 装备状态、物品冻结数值、安全箱身份和金币支出使用现有终局快照、结果回执及幂等结算；没有新增存档版本。
- 本阶段没有局内断点保存；应用中断仍沿用既有中断恢复规则。
