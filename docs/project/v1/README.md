# v1 项目文档归档

> **V1 历史归档**：正文中的“当前”“已确认”和验收结果均指 V1 时期。当前玩法设计采用 [V3](../v3/README.md)，现有代码基线见 [V2](../v2/README.md)；本页不要求保留或恢复 V1 运行代码。
