## 本轮功能

| 模块 | 入口 | 首版行为 |
| --- | --- | --- |
| 暂停菜单 | 战斗 HUD 的“暂停” | 继续游戏、设置、玩法帮助、放弃本局；打开时清除摇杆和交互输入 |
| 主动放弃 | 暂停菜单 → 放弃本局 → 确认放弃 | 只带回安全箱物品；安全箱外入场装备和战利品丢失；不退体力、不发撤离经验 |
| 玩家设置 | Home 关卡标题行 / 暂停菜单 | 音乐音量、音效音量、运行平台提供的画质档位；保存成功后应用 |
| 仓库整理 | Home → 仓库 | 默认/品质/等级/出售价格排序、物品锁定、明确多选、批售总价预览与确认 |
| 新手指引 | Home → 新手指引 / 玩法帮助；暂停菜单 → 玩法帮助 | 七页配置文本、翻页、已了解进度持久化、重复阅读；首次不强制遮挡主界面 |

## 暂停与终局边界

- 手动暂停使用 `ExpeditionPanelKind.Pause`，应用切到后台仍使用原有应用暂停。任一暂停原因存在时，都不推进战斗；从后台返回不会关闭手动暂停。
- 打开设置或帮助时，暂停菜单保留在下层。关闭上层窗口仍保持暂停，点击“继续游戏”才恢复；恢复时不补跑暂停期间的时间，不继承旧摇杆输入。反馈音效也跟随暂停。
- 三选一、局内背包、NPC 商店、强化总览沿用独立面板状态；已有交互时不能叠加手动暂停并绕过其规则。
- 主动放弃经过明确损失确认后，调用 `ProjectRunCoordinator.TryAbandonRun`。它冻结终局、保存、结算并进入结果页，最后返回 Home；不播放角色死亡动作。
- `ProjectRunOutcome.Abandoned` 与成功撤离互斥。打怪经验继续沿用当前 `KeepKillExperienceOnDeath` 策略，局内已发生的金币支出仍结算，局外技能成长不清除。
- 终局记录保存失败时沿用现有恢复页与同一笔事务重试；重复放弃、重复到账和重复退体力均被拒绝。
- 本轮没有改变进程崩溃/强杀后的原型补偿流程，也没有实现运行中断点续玩。上线前仍需独立确定异常中断策略。

## 设置与保存一致性

`ProjectPreferences` 保存音乐音量、音效音量、画质选择与指引版本，放在现有 `ProjectSaveData` 内；使用原有候选快照、持久化回执及重试机制。偏好只在 Home 空闲或本局暂停菜单中编辑，保存成功后才调整音乐/Sfx 通道与 Unity 质量设置。

旧存档缺少偏好字段时使用默认音量 100%、项目默认画质、未阅读指引；缺少物品锁定字段时默认未锁定。第一版到第三版存档迁移仍可用。画质索引在另一平台不存在时保留记录、不应用无效档位，玩家可重新选择。

`HasUncommittedSave` 同时覆盖写入中与失败待重试两种状态。局内设置或指引保存未完成时，暂停菜单禁用继续和放弃，并提供“重试保存”；战斗模拟和交互也检查该门禁，避免与终局保存重叠。

## 仓库整理规则

- 锁定只防止单件或批量出售，不阻止穿戴与入场，也不改变死亡/放弃损失。锁定状态随物品实例保存和携出。
- 排序只影响本次显示；相同品质、等级或售价保持原库存顺序，不重抽属性。
- 批量出售只处理玩家明确勾选的实例。跨类型筛选仍保留选择；确认框显示全体选中件数与总金币。退出多选会清空勾选。
- 任一实例缺失、重复、已穿戴、锁定、售价无效或总金币溢出，整批拒绝；通过后只提交一次仓库与金币快照。
- 批量出售始终确认，史诗及以上单件出售也确认。窗口关闭会取消未完成确认，迟到回执不能触发出售。
- 保存失败保留旧库存与金币，重试原候选；确认成功后只移除一次物品、增加一次金币。

## 内容配置

新增 `config/excel/CfgGuide.xlsx`，字段为 `ID`、`SortOrder`、`Title`、`Body`。七页依次介绍移动战斗、地图探索、物品安全箱、撤离死亡、三选一、局外成长、体力补给。

安全箱、入场消耗、体力上限、恢复间隔、重置与补给时间/数量使用 `CfgProfile` 占位符替换，避免帮助文案中的数值与玩法规则分叉。启动门禁校验表存在、非空、排序唯一、字段和占位符有效；错误配置不能进入正常会话。源表、生成的 C# 与 JSON 同时纳入版本管理，项目内容表总数为 30。

关键源码入口：

- `Project/ProjectRunCoordinator.cs`、`Project/ProjectRunRecords.cs`：主动放弃与持久结算。
- `Gameplay/Expedition/ExpeditionRun.Inventory.cs`、`UI/Battle/ProjectPauseWindow.cs`：暂停面板与交互。
- `Project/ProjectPreferences.cs`、`ProjectSession.Preferences.cs`、`UI/Settings/ProjectSettingsWindow.cs`：偏好与设置窗口。
- `Project/ProjectWarehouseRules.cs`、`ProjectSession.Warehouse.cs`、`UI/Warehouse/WarehouseWindow.cs`：仓库规则与界面。
- `Project/ProjectGuideConfig.cs`、`UI/Guide/ProjectGuideWindow.cs`：配置指引与阅读进度。

以上路径均相对于 `DevProject/Assets/Scripts/GameLogic/Runtime`。
