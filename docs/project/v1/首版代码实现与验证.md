## 已接入的流程

`Home → 选择关卡 → 保存入场扣费与携装 → Expedition → 地图探索/自动战斗/拾取 → 撤离或死亡 → 保存结算 → Home`

- Home 顶部显示等级、经验、体力、金币、钻石；下方选择关卡、领取补给，底部打开仓库和技能弹窗。
- 仓库按全部、武器、装备、物品分类，用单元格展示；支持详情、穿戴/卸下和出售。金币不足购买失败，不消耗钻石。
- 升级获得技能点，局外提升伤害、生命和移速；成长在入场时转换成战斗数据。技能不是掉落物。
- 地图由种子生成双向连通图，含普通怪物、Boss、NPC、战利品房。出口旁按交互即可换图，无清怪门槛；回访保留敌人、箱子和商店状态。
- 小地图显示已访问房间及相邻未知轮廓，不携带撤离字段。至少一个非起点普通战斗房有清怪后出现的撤离点，其他房间随机产生候选；非战斗房候选直接显现。
- PC 使用项目现有移动输入（WASD/方向键）和 E 交互；触屏使用摇杆和交互按钮。接近敌人自动攻击，进入绿色撤离范围自动结算。
- 普通怪物概率掉落，Boss 必掉，宝箱和 NPC 可获得随机物品。局内背包可将未穿戴物品放入安全箱。
- 成功撤离携出全部持有物品；死亡只携出安全箱物品，入场装备同样按死亡规则损失。装备、钱包、经验及技能点统一持久化，保存确认前不公开候选状态。

## ECS 战斗首版

使用项目内的轻量 ECS：实体以世界编号、槽位及代次标识；组件由 `CombatWorld` 集中存储，系统按固定 60 Hz 顺序执行。角色、施法、位移、飞弹和 Buff 都有独立状态，表现对象只读快照。

- 技能节点按整数 tick 驱动统一效果队列。示例含 0 帧提示、5 帧前冲、10 帧判定，伤害不依赖动画回调。
- 效果支持表现提示、伤害、位移、生成飞弹、添加 Buff；按 FIFO 执行，并设置每帧命令预算和递归深度限制。
- 目标和命中支持阵营、距离、地图、存活状态、圆/扇形/矩形/胶囊范围与障碍视线检查。
- 飞弹支持直线、重力抛物线、固定端点弧线和瞬时模式；提供出生锚点、追踪、丢失目标策略、速度/寿命/距离、连续碰撞、命中次数和反弹参数，命中/到达/到期可继续产生效果。
- Buff 支持同来源叠加、替换和重置时长，周期及到期处理、属性加成和效果列表。敌方时间随房间冻结，玩家状态随玩家换图继续推进。
- 换图取消玩家未完成的施法和战斗位移；旧地图敌人及当地飞弹冻结。死亡事实去重，世界释放不触发掉落或到期奖励。

这是设计中的首批运行能力。尚未实现完整配置导表/编辑器、复杂寻路、全部状态抗性/打断策略、数值乘区、正式动画资源、完整 Roguelike 三选一内容及设备性能优化。

## 原型取值与待定规则

下面都是便于代码验证的集中参数，可在 `PrototypeRules`、`PrototypeLevelConfig` 和 `ExpeditionRun.CreateCatalog` 迭代，不应当作正式平衡结论。

| 项目 | 当前代码取值 |
| --- | --- |
| 地图 | 每局 10 张，5×2 格点、1～2 条额外连接；房内使用统一占位布局 |
| 撤离候选 | 1 个普通战斗房保底，其他非起点房额外概率 20% |
| 安全箱 | 2 件，已穿戴入场装备不能直接放入；局内尚无换装操作 |
| 成长 | 每级门槛 `100 + (等级 - 1) × 50`；每升一级 1 点技能点 |
| 技能 | 3 项，各 5 级；提升到第 N 级消耗 N 点技能点 |
| 关卡解锁 | 三档关卡分别需要角色 1/3/6 级 |
| 奖励 | 击杀经验 `10 + 关卡档位 × 3`，成功撤离另加 40；经验在结算保存时入账 |
| 死亡经验 | 原型暂时保留击杀经验，由 `KeepKillExperienceOnDeath` 控制，正式规则仍待确认 |
| NPC | 每张 NPC 图 1 件随机商品，20 金币，支出随本局结算保存；局外商店目录尚未实现 |
| 物品 | 武器随机伤害/范围，装备随机生命加成，普通物品可出售；具体品类及词缀待扩展 |
| 体力 | 上限100、入场10、6分钟恢复1；UTC+8 5点重置100，0/12/18点补给40 |
| 补给边界 | 当时段至下一补给时段可领一次，允许领取后超上限；5点重置不重发0点补给 |
| 异常中断 | 不恢复半局；返还原入场装备及入场体力，舍弃未结算战利品、经验和消费 |

异常恢复是原型开发便利策略，未提供防回档作弊能力。当前本地时钟用于体力，不具有服务端时间权威。钻石只展示和保存，无兑换或高级消费项目。

## 保存和失败恢复

- 出战先生成逻辑图和世界，再保存扣体力及入场装备托管，确认后进入场景。
- 结算用单局 ID 去重，装备携出、经验升级与金币支出合并为一次快照。
- 保存失败保留同一候选并阻止新交易，Home/HUD 提供重试；回执必须覆盖该候选修订号，避免旧回执误报成功。
- 入场准备、切图或战斗执行异常时采用上述开发恢复策略；不会将未完成的逻辑错误算成角色死亡。

## 运行入口

Unity **2022.3.62f2** 打开 `DevProject`，等待编译，再执行 **Tools → Unity Mini Game Framework → Prepare GamePackage**。从固定的 `Assets/Scenes/Main.unity` 启动即可进入 Home；关卡和界面内容由项目代码创建，无需新建或手工绑定战斗 Scene/Prefab。
