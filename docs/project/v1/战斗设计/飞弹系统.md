## 1. 定位与边界

飞弹是由 `CombatWorld` 管理、具有稳定实例身份和速度的战斗实体。它可以沿直线飞行、按重力弹道飞行、沿固定终点的抛物线飞行，或在创建点立即结算命中。命中只产生效果执行请求；伤害、Buff、位移等效果按统一效果管线处理。普通近战自动攻击仍可直接使用技能时间轴判定，不必生成飞弹；武器附加效果、角色战斗技能、敌人技能可按定义生成飞弹。

M03 独占 `CombatWorld` 的运行状态与权威结算；M05 持有配置并提供无副作用的属性/效果计算，不自行推进飞弹或修改生命。使用自有 ECS 风格数据和系统，不把安装 Unity DOTS、Jobs 或 Burst 当作前提。`CombatSkillDefinition`/`CombatSkillId` 是战斗时间轴定义，`CastId` 标识一次施法；局外成长仍使用 `SkillDefinition`/`SkillId`，普通攻击和敌人战斗技能不必映射成长 `SkillId`。飞弹定义为 `ProjectileDefinition`/`ProjectileId`，运行实例为 `ProjectileInstanceId`。

## 2. 定义、实例与身份

### 配置定义

| 配置组 | 拟议字段与约束 |
| --- | --- |
| 基础 | `ProjectileId`、配置版本、表现资源、所属碰撞阵营、`SpawnAnchor`（`Source`/`TargetPointSnapshot`/`TargetEntityAtSpawn`）、出生偏移及偏移所用朝向基准 |
| 运动 | `MotionKind`：`Straight`、`GravityArc`、`FixedEndpointArc`、`Instant`；速度、可选加速度、转向角速度、重力向量、目标高度、最大路程、最长寿命按模式校验 |
| 目标 | `TargetBinding`：方向快照、点快照、实体快照、实体锁定；目标丢失策略；是否只允许命中指定目标。锁定只影响导向和合法目标判断，不绕过墙体或碰撞 |
| 碰撞 | 飞弹半径/形状、阵营与目标过滤、墙体响应、角色响应、最大穿透目标数、最大弹射数、同目标重复命中间隔与上限 |
| 效果 | `OnHit`、`OnArrive`、`OnExpire` 的效果引用和触发条件；终止原因优先级；终止效果互斥键。`OnDestroy` 仅作清理/表现通知，不再次执行伤害或爆炸 |

配置表只保存定义，不保存可变的目标生命或世界位置。非法组合在配置导入或进入战斗前拒绝，并记录明确错误；不能在运行中偷偷降级为另一种弹道。

### 运行实体组件

| 组件或状态 | 内容 |
| --- | --- |
| `ProjectileIdentity` | `ProjectileInstanceId`、`ProjectileId`、`EntityRef`、创建 `CombatTick`、所属 `RunId`/`RoomId`、配置版本 |
| `ProjectileTransform` | 当前/上一模拟位置、朝向、当前速度向量、累计实际路程、出生偏移后起点 |
| `ProjectileMotion` | 模式参数、剩余寿命、最大路程、重力/加速度、固定弧线起点/终点/总 tick/已过 tick、剩余弹射数 |
| `ProjectileTarget` | 方向或点快照、目标 `EntityRef`（若有）、上次有效目标点、导向与丢失策略 |
| `ProjectileCollision` | 形状、过滤器、已穿透次数、按目标 `EntityRef` 记录上次命中 tick/次数的 `HitHistory`、去重窗口 |
| `ProjectileLifecycle` | `Active`/`TerminalPending`/`DestroyPending`、终止原因、`OnSpawn`/`OnHit`/终止回调已处理标识、已发出的触发键和结构销毁代次 |
| `ProjectileContext` | `RunId`、`RoomId`、`SourceEntity`、`InstigatorActorId`、`RootExecutionId`、`TriggerId`、`EffectInvocationId`、`ParentInvocationId`、可选 `CastId`，以及发射时的攻击属性快照 |

`EntityRef` 包含世界身份、实体槽位与 `generation`，查找时三者均须匹配；实体槽位复用不会把旧飞弹或旧目标误认作新实体。`ActorId` 是归因身份，不代替可失效的 `EntityRef`。`ProjectileInstanceId` 在一次 `RunId` 内唯一，序列化或回访时保持原值；重复创建请求按施法实例、时间轴事件与创建序号去重。效果执行继承根链身份：新效果有自己的 `EffectInvocationId`，保留 `RootExecutionId`，并把触发它的调用写入 `ParentInvocationId`。根链深度与单 tick 预算遵循主战斗框架，不在本文另定常数。

## 3. 出生、目标与合法组合

`SpawnAnchor` 决定出生基点：`Source` 取发射者当次位置；`TargetPointSnapshot` 取已确认的目标点快照；`TargetEntityAtSpawn` 在创建当次校验目标 `EntityRef` 后取其位置快照。三者均可配置局部偏移，且须显式指定偏移的朝向基准：施法者朝向、有效目标朝向或定义给定朝向；点本身没有朝向，不能隐式读取。`TargetEntityAtSpawn` 只用于出生取样，不代表创建后持续追踪。所有出生锚点均校验同 `RunId`/`RoomId`、有效世界位置和不可穿越的场景障碍占用；目标角色与飞弹判定体重叠是合法命中候选，不因与角色重叠而拒绝在目标处生成；使用 `TargetEntityAtSpawn` 时另校验目标实体未死亡且代次有效；无效时创建失败并反馈触发技能，不生成半初始化实体。`Source` 锚点若沿发射线偏移，还要做出生阻挡检测，不能无条件把飞弹推到墙后；目标点/目标实体锚点可直接在合法目标位置出现，**无需扫掠发射者到出生点的连线**。施法距离与视线（LoS）仍按 `CombatSkillDefinition`/效果配置校验，出生锚点不能绕过这些条件。发射时缓存进攻侧属性和归因身份；命中时读取目标当时的防御与 Buff 状态。发射者此后死亡，默认已发射飞弹继续飞行和归因；允许定义选择随发射者死亡销毁，但不能把伤害归给复用该槽位的新实体。

| 运动模式 | 合法目标绑定与导向 | 不合法组合 |
| --- | --- | --- |
| `Straight` | 方向快照；点快照；实体快照（出生时取点）；实体锁定加逐 tick 限角转向 | 无锁定实体却配置追踪转向；静态点却称“追踪目标” |
| `GravityArc` | 方向/初速度快照；或实体/点在出生时取目标点并**只计算一次**初速度 | 飞行中追踪转向、同时启用固定终点弧线参数 |
| `FixedEndpointArc` | 点快照；或实体在出生时取目标点快照；飞行中终点不变 | 运行中实体锁定、追踪转向、额外线性加速度/重力 |
| `Instant` | `Source`、目标点快照或目标实体创建当次快照均可作为出生锚点；在该点按配置形状立即查询，目标实体只在本次校验/取样 | 速度、加速度、寿命倒计时、逐 tick 转向、飞行中目标丢失策略 |

“实体快照”只把发射瞬间实体位置转为点，不意味着以后持续锁定。首版抛物线默认使用**目标点快照**，目标移动后仍飞向原终点；不能把它描述为追踪抛物线。若未来需要追踪弧线，须单独定义可复现的重规划运动模式及其命中、路径和网络/回放规则。

`Straight` 实体锁定每 tick 读取目标 `EntityRef`，按最大转向角 `ω × Δt` 从当前方向向目标方向旋转，再由速度推进；锁定不保证必然命中。目标死亡、换图、失效或 `generation` 不符时按配置执行 `ContinueLastDirection`、`FlyToLastKnownPoint` 或 `Expire`，且丢失策略只能用于实体锁定模式。`FlyToLastKnownPoint` 后不重新捕获新目标。默认建议继续最后方向，具体产品规则待试验。飞弹不跨图寻找目标；非当前地图的飞弹按该地图局部钟冻结。

## 4. 运动公式与终点

建议战斗以固定 `CombatTick` 推进，首版取 60 Hz 供验证，`Δt = 1 / 60` 秒；这是实现建议而非已确认帧率。运动和寿命均用模拟 tick，不读渲染帧 `deltaTime`。所有运动模式从创建后的**下一 tick**开始运动，`Instant` 是例外：它在已校验的出生锚点（可为目标点或目标实体当次位置）把命中查询放入当次效果队列并立即排空，不参与飞行寿命、速度除法或下一 tick 运动。瞬时实例没有跨帧追踪。

| 模式 | 每 tick 位置/速度计算 | 参数边界 |
| --- | --- | --- |
| 直线 | `dₙ` 为当前单位方向；`sₙ₊₁ = clamp(sₙ + a × Δt, 0, sMax)`，`pₙ₊₁ = pₙ + dₙ × sₙ₊₁ × Δt`。若锁定目标，先限角更新 `dₙ`；加速度只沿当前方向改变速率 | 初速 `s₀ > 0`，`sMax > 0`；加速度可为负但不能让速度小于零；失速时按配置到期，不以零速计算飞行时间 |
| 重力弹道 | `vₙ₊₁ = vₙ + g × Δt`；用 `pₙ₊₁ = pₙ + vₙ × Δt + ½gΔt²` 推进。若指定目标点和飞行时长 `T > 0`，出生时可一次求 `v₀ = (q - p₀ - ½gT²) / T` | 重力向量、初速度或目标点+正飞行时长二选一；飞行中不重算 `v₀`。命中墙/角色仍按实际扫掠轨迹判定 |
| 定点抛物线 | `u = elapsedTicks / totalTicks`，`p(u) = p₀ + (q - p₀)u + 4h u(1-u)Up`；每 tick 用前后两点扫掠。建议 `totalTicks = max(1, ceil(distance(q, p₀) / (nominalSpeed × Δt)))`，也可显式给正总 tick，二者互斥 | `nominalSpeed > 0`；速度在此模式仅决定时长，**不保证弧线实际匀速**；`h` 为相对直线的顶点抬高。加速度与重力无效且须拒绝配置 |
| 瞬时 | 以 `SpawnAnchor` 得到的出生位置和判定形状查询一次，直接生成命中/到达效果请求；目标处出现不计算发射者到目标点的飞行段 | 无飞行长度和寿命计算；即使距离为零也没有除零路径 |

直线与重力弹道按实际逐段路程累计；定点抛物线按各 tick 曲线弦段累计。`maxDistance` 是**已走路程上限**，不是出生点到当前位置的直线距离，因此弹射不能靠折返获得无限航程。每 tick 先把候选位移裁到剩余路程与本 tick 剩余寿命内，再扫掠；到达上限或寿命结束发一次 `OnExpire`。定点抛物线完成最后一个 tick、且此前没有阻挡终止时发 `OnArrive`。直线指定点可在本段跨越目标点时 `OnArrive`；纯方向飞弹没有“目标到达”，以命中、距离或寿命终止。重力弹道只在配置了终点判定区域且扫掠进入该区域时到达，不以解析式时间直接宣称命中。`Instant` 只在当次查询完成后进入销毁流程，可能发命中或到达，不发寿命到期。

若固定弧线起终点重合且高度不为零，至少使用 2 tick，让抬升和落下都有明确的扫掠段；若高度也为零，改用一次定点命中查询并到达，不做除以距离。寿命与距离上限同时达到时使用固定终止优先级；零或负的飞行寿命、最大路程由定义校验拒绝，不能依赖运行时除零后的结果。所有坐标、速度和时间参数拒绝 NaN/无穷值。

## 5. 连续碰撞、命中与多目标

每 tick 按飞弹碰撞形状对“上一模拟位置 → 候选位置”连续扫掠，不能只检查终点，否则高速飞弹会穿透薄墙或小目标。弹道曲率较大时对重力/定点弧线做确定性的子段近似，并校验最大几何误差；子段数量受统一预算约束。每段取得墙体、地形、可命中角色与目标区域候选，按首次接触比例排序；同一比例先处理实体墙体，再处理角色，角色间按稳定 `EntityRef` 排序。不可穿越墙体优先于墙后的角色，不能隔墙自动命中。每次接触后继续推进剩余段、穿透或反射时再次扫掠，直到本 tick 路程耗尽或到达统一处理预算；不可因帧率不同改变排序。

过滤步骤依次检查：同 `RunId`/`RoomId`、有效 `EntityRef`/`generation`、阵营与友伤规则、命中形状/高度、目标可受击状态、是否在同目标命中间隔内。发射者默认不在可命中集合，是否能回击自身须显式配置。命中效果进入 FIFO 队列，使用飞弹与目标的身份生成唯一命中序号；效果自身再决定伤害、Buff 或位移，不在碰撞系统内直接改生命值。

- **穿透：** `maxDistinctTargets` 建议表达最多可命中的不同目标数；每个通过过滤的目标首次命中计数，达到上限后以 `HitStop` 终止。穿透后从接触点沿剩余扫掠继续，不能重新从本 tick 起点检测并重复命中。
- **墙体：** 首版建议实体墙停止；可显式配置 `Reflect`，按接触法线反射速度方向 `v' = v - 2(v·n)n` 并扣一次弹射次数。穿墙、破坏墙和复杂材质反应留扩展；穿透角色数不能隐式穿墙。
- **弹射：** 每次反射记次数，耗尽后停止；接触后沿新方向做极小的几何分离以避免同一接触面零进度循环。分离不计作额外攻击距离，且每 tick 的接触处理必须有预算上限。定点抛物线不支持反射；反射只适用于能更新速度向量的直线/重力模式。
- **重复命中：** 默认同一 `ProjectileInstanceId` 对同一目标 `EntityRef` 只命中一次。需要周期重复伤害时，显式配置最小正整数间隔 tick 与每目标次数上限；用最后命中 tick 和次数判定。目标死亡再重建实体时 `generation` 不同，不能继承旧目标命中记录。

锁定目标与命中过滤分开：追踪某实体不等于只可命中该实体，路上的墙或其他合法敌人仍可能先被碰到；若配置 `OnlyLockedTarget`，其他角色被过滤但墙体仍有效。配置验证要阻止“实体快照但只命中失效实体”“无目标却仅命中锁定目标”等无法满足的组合。

## 6. 生命周期、回调与效果队列

拟议生命周期：`SpawnRequested → Active → TerminalPending → DestroyPending → Removed`。同一实例可以多次 `OnHit`（穿透/间隔命中），但只允许一次终止原因；`OnArrive` 和 `OnExpire` 互斥。一次命中若导致终止，先按命中接触处理 `OnHit`，然后锁定 `HitStop`/`WallStop` 等终止原因；若配置了终止爆炸，以 `(ProjectileInstanceId, ExplosionKey)` 保证只执行一次。若同一 tick 既碰角色又抵达终点，按接触比例先后处理；完全同点时墙体、角色命中优先于到达，到达优先于寿命/距离到期。`OnDestroy` 只释放 ECS 组件和触发表现回收，不再发一次战斗爆炸。

| 事件 | 触发与去重 |
| --- | --- |
| `OnHit` | 每个合法接触按唯一命中序号执行一次；穿透可产生多个序号；失败过滤不触发 |
| `OnArrive` | 真实到达目标点/区域且未先终止时一次；纯方向模式不触发 |
| `OnExpire` | 寿命或累计路程耗尽、明确的目标丢失到期等原因一次；与到达互斥 |
| `OnDestroy` | 终止后的统一结构清理通知一次，无玩法效果；对象池回收在末阶段 |

`OnHit`、`OnArrive`、`OnExpire` 可以引用同一爆炸效果，但共享该实例的终止爆炸互斥键，避免“命中后销毁又爆炸”或“到达与超时同 tick 爆两次”。若设计希望穿透沿途爆炸，每次接触须使用不同的接触键，终止爆炸仍独立且只能一次。效果调用生成新的 `EffectInvocationId` 与明确 `TriggerId`，保留 `RootExecutionId`/`ParentInvocationId`；同一请求重放时以身份去重。效果可以再创建飞弹或 Buff，但遵循统一队列深度和预算，不能递归直接调用无上限。

## 7. CombatTick 时序与跨图

建议固定阶段如下，效果请求统一进入 FIFO 队列；每个阶段要求排空其应处理队列后才进入下一阶段：

1. Buff 到期/移除效果与属性重新计算。
2. **已有**位移/飞弹运动、连续命中，随后排空其效果 FIFO 队列。该阶段效果新建的运动飞弹不会在本 tick 再运动。
3. Buff 周期效果，随后排空 FIFO 队列。
4. 输入、施法与技能时间轴效果，随后排空 FIFO 队列。此阶段新建 `Instant` 飞弹在创建点立即查询并排空效果；新建运动飞弹下一 tick 才运动。
5. 按总纲先有界收束死亡清理及其显式效果，再发布唯一死亡/清图事实，最后处理换图边界、结构销毁与表现事件。伤害效果执行时立即更新 HP 和 `DeadPending`；实体不在伤害回调中马上物理移除。

第 2、3 阶段效果若创建 `Instant`，同样在当前队列内完成即时判定；但新运动飞弹一律延后到下一 tick。飞弹在本图局部模拟钟上运行，离图后其位置、寿命、冷却、持续区域和目标敌人状态冻结；玩家活跃模拟时间在另一图继续，其自身 Buff/技能冷却按玩家时钟推进。地图加载阶段双方暂停模拟，不借加载耗时推进伤害或恢复。飞弹不能跨 `RoomId` 命中，也不跨图追击或把旧图伤害迟到地施加给新图；地图回访恢复其完整快照。当前已成立的碰撞、伤害、死亡事实须先收束再切图，不能通过卸载取消。

跨图提交成功时，玩家未完成的 `CastId` 和战斗位移按 `MapTransfer` 取消，仅做清理，技能冷却和已消费资源不退款、不重置；加载失败未提交切图时不执行该取消。已经发射的飞弹留在出生 `RoomId`，包括玩家发射的飞弹，随后随该地图冻结。飞弹目标若为已换图的玩家，旧图再次激活后按同图目标丢失策略处理；非当前地图被冻结的飞弹在回访前不会主动追踪新图玩家。源实体死亡时默认飞弹仍存活；如果定义显式要求随源死亡销毁，统一标记终止且保留已成立命中和正确归因。对象池回收仅在第 5 阶段，旧引用与旧事件校验 `RunId`、`RoomId`、世界、`generation` 及 `ProjectileInstanceId`，不能因复用槽位把迟到命中算给新飞弹。

离图快照和回访恢复保存 `HitHistory`、终止原因、触发键与各回调已处理标识。恢复只是重建运行状态，不重新执行 `OnSpawn`、既有 `OnHit` 或已处理终止效果；对象池的 `OnDestroy` 与 GC 回收也不产生额外爆炸。

## 8. 配置示例与验证

以下仅展示结构和边界，数值为**测试占位**，并非正式平衡配置：

| 示例 | 运动/目标 | 碰撞/终止 | 要验证什么 |
| --- | --- | --- | --- |
| 直线短刃波 | `Straight`，速度 12 单位/秒、寿命 90 tick，方向快照 | 半径 0.2、最多命中 2 个不同敌人、遇墙终止 | 高速扫掠、穿透两目标、墙先于墙后敌人 |
| 追踪飞刃 | `Straight`，速度 8、每秒最大转向 120°，实体锁定 | 目标丢失后沿最后方向，默认同目标一次 | 目标移动、死亡、换图、实体槽复用时不错误追踪 |
| 投掷弧线 | `GravityArc`，目标点快照、正飞行时长 0.8 秒、重力向下 | 墙/角色连续扫掠，落地到达区域触发一次效果 | 初速度只算一次，目标移动后不变成追踪 |
| 定点落刃 | `FixedEndpointArc`，点快照、名义速度 10、高度 2 | 终点区域到达触发一次范围效果 | 弧线寿命、路程、终点与目标同点边界 |
| 原地爆发 | `Instant`、`SpawnAnchor=Source`，发射者位置一次半径判定 | 当次效果队列入队、一次销毁 | 零速度/零距离也不除零、不重复爆炸 |
| 目标处落刃 | `Instant`、`SpawnAnchor=TargetPointSnapshot`（或有效 `TargetEntityAtSpawn`），目标点偏移按显式朝向取样 | 目标位置当次范围判定，命中/到达效果只结算一次 | 同图、目标存活、合法落点、施法距离/LoS 校验；不扫掠起点至目标，也不跨帧追踪 |

首版推荐实现顺序：①稳定身份、直线/瞬时、扫掠与终止去重；②固定终点弧线和重力弹道；③实体锁定转向、丢失策略和反射/重复命中。顺序是开发切片建议，不改变用户确认的技能效果需求；若首批内容需要后两类能力，应按依赖提前实现。首版以球/胶囊扫掠和少量明确碰撞层支持必需内容；复杂曲面弹射、弹道重新规划、跨图追击与任意地形破坏留扩展。

后续验收至少覆盖：固定 seed 与 `CombatTick` 下轨迹和命中序列可复现；创建当 tick 的运动飞弹不提前移动，`Instant` 当次结算；高速飞弹不穿墙/角色；墙体与角色同距离时墙优先；穿透/弹射与同目标间隔不多发效果；命中/到达/到期/销毁不重复爆炸；目标或源死亡、切图与回访、加载暂停、对象池 `generation` 复用仍保持身份、归因和唯一事件；配置非法组合在进入战斗前被拒绝。这里仅是设计验收条件，当前未执行 Unity 验证。
