## 内容与触发

正式数值以 [Excel 源表](../../../config/excel/) 为准，经导表生成 JSON 与 C#；当前共有 27 张项目内容表。新增 CfgAdvancedAffixes 与 CfgCombatAugments，扩充 CfgQualities.AdvancedAffixCount 和 CfgRogueRewards 的增益、阶级、前置及互斥字段。两张新表与既有内容一并加载和校验，运行时缺配置会使启动或对应内容创建失败。

七种战斗增益为割裂流血、暴击追伤、击杀回复、受伤反击，以及基础攻击冷却、范围、伤害修正。装备高级词条以物品类型和最低品质筛选，按权重无放回抽取：普通/精良/优秀为 0 条，史诗与传说各 1 条，神器 2 条。武器和护甲使用不同候选；词条定义在单件物品内不重复。

三选一奖励池新增 8 个战斗增益奖励：上述七种加“嗜血追猎”。嗜血追猎需割裂达到 2 级；疾风架势与重击架势属于同一互斥组。奖励等级和选取组在单局内保留，物品奖励仍沿用背包、撤离携出和死亡安全箱规则。宝箱原有战利品与三选一保留；首次 Boss 清房必出三选一，小怪房按配置的 45% 概率抽取。同一稳定来源只发一次，回访不重复授予。刷新和第四项授权仍默认关闭，未接广告提供器。

RogueChoiceWindow（2500）负责暂停中的三选一；RogueOverviewWindow（2501）展示本局已选强化。三选一、总览、背包、商店和应用后台有各自的暂停门禁；退出窗口或返回前台不跳过待选奖励。

## 装备实例与存档

新生成装备的 EquipmentVersion 为 2。ProjectItem.AdvancedAffixes 保存每条词条的 DefinitionId、AugmentId、效果 Version 和冻结后的 Value；复制、换装、换房、保存及读取均不重新抽取。生成时以当前表中的权重、品质要求和 ValueMin/ValueMax 抽取。详情用效果标题与说明展示冻结值，说明中的 {value} 替换为百分比。

存档 schema 仍为 3。已有 EquipmentVersion=1 装备允许高级词条字段缺失或为空，不补抽；更早版本的装备迁移仍按原数值升级到版本 1。新版实例要求高级词条定义、增益身份、版本、物品类型、非重复身份及数值结构有效；概率值必须在 0～1，每个冷却、范围、伤害倍率须处于 ECS 的 0.1～10 安全范围内；冷却缩减值按单精度换算后不得低于最小倍率。已保存实例不再按当前品质词条数量或随机值区间重新裁定，调权重、生成区间或品质数量只影响以后新生成的物品。每件上限 32 条，战斗中两件装备合计不超过 64 条。删除已发放的定义、改变效果版本或物品适用类型仍可能使旧实例无法读取，须先设计对应版本兼容或迁移。

ValueMode 的存储和计算约定：

| 模式 | 冻结 Value 的含义 | 运行计算 |
| --- | --- | --- |
| 0 效果强度 | 基础效果系数，可大于 1；当前追伤/回复/反击表为 0.8～1.2 | 效果固定值与攻击系数乘以 Value |
| 1 触发概率 | 绝对概率，范围 0～1 | 以 Value 判定触发 |
| 2 技能修正 | 比例 | 冷却乘 1-Value；范围、伤害乘 1+Value |

## 战斗边界

词条效果与局内流派经配置映射为局内增益，不改共享 CombatCatalog。同一独立分组的新配置替换旧配置时，保留内部触发冷却和已经生成的施法、飞弹、Buff 等在途快照；后续新施法按当前装备及流派计算。被动产生的衍生伤害、回复等效果不再次触发被动，防止流血或反击链式自触发。玩家换装只更新之后的基础攻击、范围和增益构成；角色当前生命、已接受的局内强化、冷却及在途效果按原战斗状态保留。

同来源的同类 Buff 再次施加并合并时，整个实例改用本次施加的属性快照；单纯卸装不会改动旧 Buff。主动与被动衍生实例分开合并，避免相互改变再次触发的资格。

局内流派不写入装备随机词条、局外技能等级或存档；正常终局仍只通过既有结算保存物品和金币。中途战斗与待选三选一不提供断点存档。
