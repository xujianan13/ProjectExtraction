## 定位与已确认规则

M02 负责第三人称俯视角色的局内移动，以及统一基础近战的自动索敌与攻击意图。

- 角色在攻击范围内有目标时自动攻击，不设置基础攻击按钮。
- 只保留近战武器，所有武器共用一种基础攻击方式。
- 武器以攻击范围等属性及武器附加效果形成差异；随机属性由 M05 提供。武器附加效果与局外提升的角色技能分开建模，保留和叠加形式待定。
- Mobile 和微信小游戏优先，同时适配 PC；默认竖屏并兼容横屏。
- 索敌优先级、切换目标、攻击方向、移动与攻击的关系尚未确定。

## 职责与边界

1. 接收平台无关的移动意图，由 M02 移动系统在 M03 持有的 CombatWorld 内更新位置与朝向；行动限制读取统一控制状态，不另存一套战斗坐标。
2. 从 M03 提供的可攻击目标集合中筛选目标；按 M05 给出的有效攻击范围和节奏形成基础攻击意图。
3. 提供当前移动、目标、攻击准备等只读状态，供 M08 表现与交互反馈使用。
4. 将自动普攻作为 AutoBasicAttack 的 CastIntent 提交给 M03；施法准入、时间轴、效果队列、命中、伤害和死亡统一执行，M02 不另开攻击计时器或自行扣血。
5. 不生成房间、敌人、掉落，不更改背包或装备的位置，也不修改角色技能等级与技能点。
6. M05 依据 M07 提供的 `SkillProgressionState` 计算角色技能效果，并计算武器附加效果；M02 只消费已计算结果，不自行升级或扣除技能点，基础攻击形式保持统一。
7. 管理第三人称俯视相机的跟随及移动方向参照，依据战斗表现指令协调攻击动画、角色音效与动作反馈；Animator/AnimationEvent 不驱动权威命中，UI 布局由 M08 负责，相机角度、距离与遮挡策略待原型确定。

## 输入、输出与依赖

| 方向 | 内容 | 来源或去向 |
| --- | --- | --- |
| 输入 | 移动意图、输入启停 | M08；输入设备由适配层处理 |
| 输入 | 当前房间的可攻击目标及目标状态 | M03、M04 |
| 输入 | 有效移速、攻击范围、攻击节奏及效果修正 | M05 按 M07 的 `SkillProgressionState` 与已装配装备计算 |
| 输入 | 单局与角色生死状态 | M01、M03 |
| 输出 | CombatWorld 中的角色位置、朝向和行动只读快照 | M04、M08；M03 系统直接读取同一世界 |
| 输出 | 带攻击源、CombatSkillId、目标或目标点的 CastIntent | M03 准入并创建唯一 CastId |

共享标识候选为 `RunId`、`RoomId`、`ActorId`、`SourceId`。
这些名称只表示模块间拟定契约，具体类型、事件和 API 在实现切片时确定。

## 最小实现切片

### 切片 1：移动闭环

- 用占位角色与俯视相机完成局内移动、停止、朝向变化和相机跟随。
- 在一个测试房间内约束角色位置；房间边界由 M04 提供。
- 从统一输入意图驱动角色，先在 Editor 验证触控与键鼠映射。

### 切片 2：自动近战闭环

- 接入一个可攻击的占位敌人，支持进入与离开攻击范围。
- 自动索敌后提交统一基础攻击的 CastIntent，由 M03 时间轴决定效果时刻；首个样例可用 0 帧动画、5 帧前冲、10 帧扇形判定。
- 目标死亡、离开范围或角色死亡时停止继续提交该目标的攻击意图。

### 切片 3：属性接入

- 从 M05 读取两件武器的不同范围或攻击节奏，验证同一攻击逻辑下的属性差异。
- 表现与判定分离；动画尚未齐备时仍能验收逻辑。普通移动、强制位移与技能前冲在统一运动阶段按优先级处理。

## 后续扩展

- 待规则确定后加入目标优先级、遮挡、切换目标及转向策略。
- 按性能预算处理大量敌人的候选目标查询与移动碰撞。
- 消费 M05 基于已保存技能等级算出的效果，以及武器附加效果对属性或统一攻击结果的修正；不自行执行局外技能提升，也不引入武器专属基础操作。

## 可操作验收标准

1. 在测试房间中，角色接受移动意图后移动，释放意图后停止，并受房间边界约束。
2. 敌人进入有效范围后，角色无需攻击按钮即可周期性产生基础攻击意图。
3. 敌人离开范围或死亡后，M02 不再向该目标提交新的攻击意图。
4. 更换不同属性的近战武器后，攻击范围或节奏按 M05 结果变化，操作方式不变。
5. M03 的命中结算关闭时，M02 不会独自改变敌人生命值或生成掉落。
6. 移动方向与确定的相机参照一致，切房后相机跟随正确；横竖屏下角色及主要战斗区域可读，相机参数不与 UI 固定像素坐标绑定。

## 决策待定

- 自动索敌的优先级、目标切换时机、遮挡和攻击方向规则。
- 攻击过程中是否允许移动、位移打断和受击中断的规则。
- 按技能判定分册选择基础近战形状和数值；验证逻辑帧与动画同步、索敌和伤害窗口的手感。
- 移动输入的具体交互、角色碰撞体参数及平台性能目标。
- 俯视相机角度、距离、跟随方式，移动方向参照与场景遮挡策略。
