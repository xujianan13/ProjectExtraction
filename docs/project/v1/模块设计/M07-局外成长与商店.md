## 当前实现与设计边界

第六阶段已接入局外金币商店，商品、价格、等级和库存由 Excel 配置；购买与已有仓库出售、装备、出战和死亡结算构成补给循环。当前购买使用持久化修订号拒绝重复旧报价，保存失败重试原候选；尚未实现通用交易回执查询或钻石商品。实际 API、累计限购策略及本轮验证见[局外金币商店首版实现](../局外金币商店首版实现.md)。以下模块设计中未标记落地的规则仍是后续目标。

## 目标与已确认规则

- 打怪和成功撤离产生角色经验，经验达到门槛后自动升级；两类来源分别记录并去重。
- 已确认等级控制高级装备穿戴、关卡解锁和局外购买资格。角色升级获得技能点，玩家仅在局外消耗技能点提升角色技能。
- 角色技能是已保存的成长状态，不是高级装备或可携物品；不设技能装配资格，不进入背包、安全箱、掉落、商店物品或出售流程。
- 五项主要属性仍是等级、经验、体力、金币、钻石。技能点在技能面板及主界面技能按钮角标展示，不成为第六项主要属性或金币、钻石之外的货币。
- 金币用于购买物品等常规消耗，出售战利品可获得金币；钻石是独立高级货币，来源、用途和价格待定。NPC 房商店与局外商店均保留。
- 死亡时是否保留本局打怪经验、局内等级何时生效待定；不预设死亡额外经验或等级回退。

## 职责边界

| 领域 | M07 负责 | 其他模块负责 |
| --- | --- | --- |
| 经验与等级 | 维护已确认生效的经验、等级及奖励去重；自动处理跨多级升级 | M03 提供战斗事实；M01 冻结单局终态与协调结算；统一项目存档入口提交 |
| 等级资格 | 判断装备穿戴、关卡准入、局外购买资格并返回锁定原因 | M05 提供装备要求；M06 穿戴前查询；M01 入场前查询 |
| 技能成长 | 独占技能点授予/消费、`SkillProgressionState`（技能等级与可用点数）、局外升级事务与去重 | M05 提供 `SkillDefinition`、升级成本和各等级效果；M08 展示及发起意图 |
| 钱包 | 维护金币和钻石独立余额与交易变化 | M09 管体力；M06 管物品归属、位置、堆叠和容器 |
| 商店与出售 | 按上下文报价、判断资格、扣指定货币或售物增金币 | M05 提供物品描述；M06 校验并交付或扣除物品 |

M07 的技能点只用于技能成长。技能升级成本若最终包含其他资源，必须另经规则确认；本草案不默认金币或钻石消耗。

## 数据与接口草案

- `ProgressionState`：已确认生效经验与等级，按经验曲线推导等级；若保存等级缓存，校验与有效经验一致。未提交的局内经验不能当作永久成长状态。
- `ExperienceEvent`：建议记录来源、数值和唯一身份。打怪事实建议以 `(RunId, DeathId)` 去重，实际按击杀、伤害或参与计奖的口径待定；成功撤离以 `RunId` 去重。
- `ExperienceGrantPlan`：未提交经验、预期等级变化和逐级奖励计划。跨越多个等级时依次处理每个新等级，各等级奖励仅发一次；重试同一经验事实不得重授点数。
- `SkillProgressionState`：在同一玩家成长存档中保存可用技能点、按 `SkillId` 记录的已提升等级，以及必要的等级奖励/事务去重记录。不含 `ItemInstanceId` 或物品位置。
- `SkillUpgradeIntent`：建议包含 `TransactionId`、`SkillId`、预期当前技能等级与配置版本；仅局外技能面板可发起。M07 读取 M05 的技能定义及升级成本。
- `LevelRequirement`：M05 装备定义、关卡和局外商品配置提供要求，M07 与已确认等级比较。角色技能成长无需“装配等级门槛”；未来技能前置条件另行设计。
- `WalletState`：建议以非负整数分别保存金币、钻石。钱包不是 M06 背包物品；货币死亡政策仍待定。
- `ShopContextId` 与 `ShopOfferId`：区分 NPC 房和局外报价；商品含指定币种、整数金额、版本、数量与适用等级要求。局外购买不依赖进行中的单局。
- `TransactionId`：玩家存档内唯一标识，标记技能升级、购买、出售及明确的货币发放；重试同一 ID 须校验操作内容一致，不得以换 ID 重复扣款或发奖。经验来源去重还需自身稳定来源身份。
- `SaleIntent` 与 `SaleQuote`：只对可售物品实例或允许堆叠的数量报价，校验归属、位置、装备状态和版本。角色技能与技能点均不可出售。

拟议字段均待实现时定型，不能当成现有公开 API。

## 成长与技能点授予

1. M03 提供唯一战斗事实，M07 按最终计奖口径规划打怪经验。M01 在成功撤离终态规划撤离经验，不重复汇总已计奖怪物。
2. M07 仅以**已确认生效**的经验计算旧等级和新等级。对 `oldLevel + 1` 到 `newLevel` 的每个新等级，逐级查询奖励配置、累加应授技能点，并将奖励身份写入去重记录。每级授予多少点待定，不能默认每级 1 点。
3. 经验、等级结果、技能点授予与去重记录应在同一成长提交中持久化。提交失败不能显示已保存升级或技能点；相同事件或结算重试不得再次授予。
4. 打怪经验死亡保留和局内生效时机尚未确定。只对按最终规则真正生效的等级发放技能点，不对临时经验、未确认的局内等级预发永久点数。
5. 死亡结算只处理已确定的经验规则和物品损失；已经保存的技能等级和技能点作为局外成长记录，不随安全箱外物品丢失而清除。

## 局外技能升级事务

1. 玩家从局外技能面板选择目标技能和下一等级，M08 仅提交意图，M07 读取最新 `SkillProgressionState` 与 M05 对应 `SkillDefinition`。
2. M07 验证当前处于局外、技能定义存在、当前等级与意图一致、目标等级合法且未超过配置上限、前置条件满足，并按配置计算下一等级技能点成本。成本、等级上限和前置规则尚待配置，不写死数值。
3. 校验可用技能点足额，扣除后不得为负；不默认附加金币或钻石费用。拒绝时技能点和技能等级均不改变。
4. 将“扣除技能点 + 提升该技能等级 + `TransactionId` 完成记录”作为一次项目存档提交。保存失败时不发布成功；相同 ID 重试返回已提交结果，内容不一致则拒绝。
5. M05 根据已保存的技能等级计算效果；M08 只有读取到保存结果后才更新等级、剩余技能点和按钮角标。局内不允许消费技能点升级。

## 购买流程

1. M07 按 `ShopContextId` 和配置形成报价，M06 提供库存；局外商店无需当前 `RunId`。
2. 购买前校验报价、局外商品适用等级要求、指定币种余额、库存、数量和目标容器。NPC 房是否采用等级门槛待定。
3. 常规消费按金币报价只扣金币，高级消费按钻石报价只扣钻石；对应余额不足则整笔失败。M07 扣款与 M06 交物通过统一项目存档入口原子提交。
4. 相同 `TransactionId` 重试返回原结果，不重复扣款或发货；失败时余额与物品位置均不变化。角色技能升级不走购买装备流程。

## 出售流程

1. 玩家主动选择实际持有的可售战利品；M07 按 M05 分类与实例属性给出金币报价，M06 校验实例或堆叠的所有权、位置和数量。
2. 校验报价版本及装备状态；不能因出售请求默默卸装。可售类别、地点和价格规则待定，但角色技能及技能点从来不是出售对象。
3. M06 移除相应物品，M07 增加金币，两者与 `TransactionId` 原子提交；重试不重复卖出或发币。出售不默认创建回购库存或钻石收入。

## 验收场景

以下是未来实现的验收条件，本轮未执行代码或游戏测试。

1. 打怪与成功撤离各发一次对应来源经验；重复战斗事件和撤离回调不重发。跨越多个等级时，每个新等级的技能点奖励恰好授予一次。
2. 经验提交失败后，已保存等级和技能点不变；重试成功后两者一致。死亡时未确认保留的临时打怪经验不产生永久技能点。
3. 等级不足时高级装备穿戴、受限关卡和受限局外购买分别失败；不会因等级不足禁止持有或携出已拥有的装备。
4. 局外升级校验配置成本、当前等级、上限、前置和足额技能点；成功时点数减少、目标技能等级增加，重开存档一致。相同 `TransactionId` 重试不再次扣点；保存失败或局内请求不改变状态。
5. 正常撤离与死亡均不将技能当作战利品处理；死亡丢失安全箱外物品时，已保存技能等级和可用技能点仍在。
6. 局外金币购买扣金币并交物一次，钻石消费只扣钻石；指定币种不足、报价失效、售空或容器拒收时，钱包与物品均不变化。
7. 出售实际持有的可售战利品，恰好扣物并增加一次金币；重复交易、失效实例或报价均不能使物品与金币不一致。
8. 技能点在技能面板与主界面技能按钮角标可见，不挤入五项主要属性；按钮点击但升级尚未提交时不提前显示新等级。
