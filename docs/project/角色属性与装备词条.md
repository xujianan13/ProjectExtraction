# 角色属性与装备词条

更新日期：2026-10-01。范围：角色战斗属性、武器与护甲、六档品质、默认属性和随机词条。本文中的公式、词条数量和掉落权重是首版可调参数；品质顺序、颜色和属性种类来自本轮明确需求。

## 属性口径

局外等级、经验、体力、金币、钻石继续保留。以下是独立的角色战斗属性，局外按已保存穿戴与技能成长展示，入场时转换成 ECS 角色数据。

| 属性 | 首版含义 | 单位 |
| --- | --- | --- |
| HP | 最大生命；关卡内另有当前生命。装备提供最大生命加成 | 点 |
| 攻击 | 技能伤害公式中的角色攻击值 | 点 |
| 防御 | 按递减收益公式抵消伤害，不直接逐点减伤 | 点 |
| 暴击值 | 换算为暴击概率：`评分 / (评分 + 100)` | 评分 |
| 暴击伤害 | 暴击时的总倍率；角色默认 1.5，即 150% | 倍率 |
| 闪避 | 命中后的伤害判定闪避概率，首版上限 75% | 比例 |
| 增伤 | 伤害乘以 `1 + 增伤` | 比例 |
| 减伤 | 防御计算后的伤害再乘以 `1 - 减伤`，首版上限 75% | 比例 |

武器攻击距离另保留为 `Range`，与上述八项属性分开。移速继续由角色基础值和已有轻装步法技能提供。所有属性使用统一计算入口，UI 不自己计算另一套战斗结果。

## 装备与品质

当前有一个武器槽和一个护甲槽，同槽换装互斥；卸下护甲不会卸下武器。护甲归仓库“装备”分类，普通物品不进入穿戴槽。

| 品质 | 颜色 | 首版额外词条数 |
| --- | --- | --- |
| 普通 | 白 | 0 |
| 精良 | 绿 | 1 |
| 优秀 | 蓝 | 2 |
| 史诗 | 紫 | 3 |
| 传说 | 橙 | 4 |
| 神器 | 红 | 5 |

- 默认属性决定物品的基本作用：首批武器提供攻击和范围，护甲提供 HP 和防御。两种装备使用同一属性列表，均可提供全部八种属性。
- 额外词条从八属性池中抽取，单件不重复抽到同种额外属性；默认属性与额外词条可以作用于同一属性。每条独立记录抽取后的值。
- 品质决定额外词条数量，物品等级与品质影响数值范围。穿戴要求等级与品质分别保存，神器不是角色等级的另一种名字。
- 随机只发生在创建实例时；查看、复制、换图、穿脱、保存、死亡去留与撤离均不重抽。品质也适用于普通物品，但普通物品不因此获得可穿戴属性。
- 颜色和品质文字同时展示，避免只靠颜色识别；仓库详情区分默认属性和额外词条，较长明细可滚动。

## 首版生成配置

配置集中在 `ProjectEquipmentRules`，无需修改 UI 或 ECS 来调整掉落分布；后续可迁入配置表。

| 项目 | 当前可调取值 |
| --- | --- |
| 类型 | 武器、护甲、物品各 1/3 |
| 品质权重 | 按白/绿/蓝/紫/橙/红为 60/22/10/5/2/1 |
| 武器默认攻击 | `12 + 2 × 物品等级 + 整数随机[0,5]` |
| 武器范围 | `1.6 + 随机[0,0.5)` |
| 护甲默认 HP | `5 + 3 × 物品等级 + 整数随机[0,5]` |
| 护甲默认防御 | `物品等级 + 整数随机[1,3]` |
| 额外词条值 | `属性系数 × 品质倍率 × (1 + 0.12 × (等级 − 1))`，保存到小数点后三位 |
| 品质倍率 | 绿 `[0.7,1.1)`、蓝 `[1,1.5)`、紫 `[1.3,1.9)`、橙 `[1.7,2.4)`、红 `[2.2,3)` |
| 属性系数 | HP 5、攻击 2、防御 1.5、暴击值 3、暴击伤害 0.04、闪避 0.015、增伤 0.025、减伤 0.02 |

新手武器仍为普通练习短刃，攻击 16、范围 1.9；本轮不额外赠送护甲。新护甲来自当前掉落、宝箱或 NPC 商品生成流程。

## 属性汇总和伤害顺序

角色默认 HP 100、移速 5、暴击伤害 150%；无武器的基础攻击为 10，有武器时使用武器属性，不再额外叠加这 10 点。武器与护甲的基础属性和额外词条相加；生命技能每级 +15 HP，攻击技能每级提供 10% 攻击倍率，移速技能每级提供 5% 移速倍率。上述均沿用或集中记录为原型参数。

命中几何、阵营、存活及遮挡判定后，统一伤害入口依次执行：

1. 基础伤害为 `效果固定值 + 来源攻击 × AttackCoefficient`；零伤害直接结束。旧效果系数默认 0，避免给已有固定伤害重复加攻击；角色近战普攻使用固定值 0、攻击系数 1。
2. 若本效果允许闪避，使用目标实时闪避率判定；闪避不扣血，并发布闪避事实。
3. 乘以 `1 + 来源增伤`。若本效果允许暴击，按来源暴击概率判定，再乘暴击伤害倍率。
4. 乘目标防御因子 `100 / (100 + 防御)`，再乘 `1 - 减伤`。
5. 扣除有限、非负伤害，发布实际伤害与是否暴击，致死进入原有死亡与结算流程。

技能、飞弹命中与 Buff 效果共用此入口。当前燃烧示例关闭暴击与闪避，仍受防御和增减伤影响。世界使用独立的确定性随机源，不消费 Unity 全局随机状态。延迟效果记录来源攻击快照，来源死亡后不丢失已经发出的攻击属性；目标防御与闪避按伤害发生时取值。

装备是入场快照；本轮不新增局内换装和局内重新分配技能点。每次出战使用当时已保存的装备与成长重新计算。

## 实例、保存与迁移

- `ProjectItem` 保存稳定 ID、类型、等级、品质、装备数据版本、默认属性列表、随机词条列表和武器范围。
- 词条保存 `DefinitionId`、属性类型和已抽取数值。所有副本深拷贝属性与词条，防止候选保存提前修改已确认记录。
- 存档 schema 升至 3，并保留 1 → 2 → 3 的迁移链。旧 `Equipment` 转为 `Armor`；旧装备按普通品质保留原 Damage、BonusHealth 和 Range 对应的结果，不补抽额外词条。
- 仓库、入场托管、待结算终局、最近结算明细中的物品均迁移，保留实例身份及原去留结果。迁移不改变经验、钱包或已完成的结算身份。
- 统一校验类型、品质、数值范围、词条身份和装备槽；非法记录不能通过保存后重新加载变成有效装备。

## 高级词条扩展方向

本轮实现基础属性词条。高级词条以稳定的 `DefinitionId` 和版本化参数扩展，未来在定义与解析层增加处理器，保持实例里的随机结果不变。

| 未来种类 | 示例 | 接入位置 |
| --- | --- | --- |
| 条件伤害 | 对满血目标增伤、对 Boss 增伤 | 统一伤害上下文及结算步骤 |
| 技能参数 | 扩大指定技能范围、缩短技能冷却、增加技能段数 | 本局技能配置副本与时间轴创建 |
| 命中触发 | 命中施加 Buff、击杀生成飞弹 | 已确认战斗事件与统一效果执行器 |

具体高级词条效果、触发概率、叠加规则和冷却后续迭代。不能只保存描述文本就声称效果已经生效；未注册定义需明确拒绝。动态修改技能时只修改本局或本次施法副本，不污染共享技能配置，也不重写已执行节点。
