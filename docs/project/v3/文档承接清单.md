# V3 文档承接清单

更新日期：2026-10-18。

V3 规则以[线性房间闯关整体设计](线性房间闯关整体设计.md)为准。**V3 首轮实现与本机 Memory 验收已完成。** V2 保留多区域历史设计与改造基线；仅本页明确采用的稳定能力继续作为 V3 基础，旧验收不计为 V3 通过。

## 1 版本与实现边界

- V3 是当前有效实现和设计版本，新的需求、决策、源码变化与实际验收写入本目录。
- V2 是多区域历史版本，V1 是更早历史；采用线性房间不代表恢复 V1 随机连接图、混合奖励或安全箱。
- 工程只维护一套有效流程，被替代的旧代码、配置、入口、测试与无引用资产随改造删除；不建立版本开关或旧版备用副本。
- 历史数据不因代码替换或文档归档删除。旧活动局迁移与磁盘恢复仍待独立决定，当前 Memory 不读写删除旧磁盘档。
- 通用框架文档继续在 `docs/framework` 维护，不按玩法版本复制。
