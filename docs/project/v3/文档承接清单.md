# V3 文档承接清单

更新日期：2026-10-18。

V3 的玩法规则以[线性房间闯关整体设计](线性房间闯关整体设计.md)为入口。V2 文档保留多区域版本设计与当前源码的实现证据；只有本页明确采用的稳定能力和工程约束继续作为 V3 基础，旧玩法规则不自动延续。

## 1 版本与实现边界

- V3 是当前设计和后续开发版本，尚未完成代码改造。
- V2 是现有运行代码的实现基线与历史玩法版本；V2 验收结果不计入 V3。
- V1 是更早的历史资料。V3 虽采用房间结构，也不恢复 V1 的随机连接图、混合奖励、安全箱等旧规则。
- 后续新增或变化的项目设计、决策、实现和验收写入 V3。历史正文只做必要勘误、版本提示与链接修复。
- 通用框架文档继续维护在 `docs/framework`，不按项目玩法版本复制。

## 4 需要替换的多区域职责

V3 按阶段替换多区域序列、区域地图导航与标记、个体定时复活、区域出口条件、跨区域旧世界保留，以及与其绑定的配置和测试。是否复用某项底层算法以实际依赖为准，不因目录名含区域就批量删除通用功能。

新房间关卡只能维护一套生效流程。对应替换完成时，同批删除被替代的业务代码、配置、调用入口、测试和无引用资产；不建立 V2/V3 版本开关、备用实现或 V1 代码副本。

本轮只调整文档，不删除代码或资产。历史玩家数据不随文档归档删除；旧活动局迁移、阻塞或其他处理由 D7 决定。
