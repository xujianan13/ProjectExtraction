# 线性房间闯关整体设计

更新日期：2026-10-18。状态：**V3 首轮实现与本机 Memory 验收已完成。** 本文记录本轮用户已确认规则；平台和旧档迁移仍按第 6 节边界处理。实际验收见[实施计划与验收](实施计划与验收.md)。

首轮与上轮已验收记录分别见实施计划 6.1、6.3，`ba019ea` 为前一轮提交。本文采用本轮 Boss 宝箱、出口确认及摇杆速度契约，已通过本机 Memory 验收、尚未提交；实际结果、失败修复与限制见[6.4](实施计划与验收.md#64-摇杆速度boss-奖励宝箱与出口结算)，不沿用历史数字代替本轮结果。

## 1 已确认方向

| 编号 | 规则 |
| --- | --- |
| R1 | 线性房间单向推进，包含怪物、宝箱、NPC，最终房为 Boss；长条地图下方进入、上方推进 |
| R2 | 击杀经验归永久角色等级，升级获得永久技能点；没有旧 Rogue 随机三选一 |
| R3 | 固定携入装备与关卡背包分离；携入不可局内更换且始终归还，所得与购入仅进关卡背包 |
| R4 | 可暂离主城并继续同局；战斗房重建敌人，玩家保留检查点状态与已发生收益消耗，奖励按稳定槽位去重 |
| R5 | 广告完成后从关卡背包选 0 到 3 件撤离；死亡可无限次广告原地满血复活；最终 Boss 掉箱，触碰开启原三轮三选一，全领后经出口确认带回全部 |

上述规则替代 V2 多区域、区域尾王、刷怪三选一、个体定时复活和携入物全损规则。仍适用的底层能力见[文档承接清单](文档承接清单.md)。

## 2 关卡与房间

### 2.1 线性循环

主城整备 → 首次扣费并托管固定出战装备 → 当前房间 → 完成后进入下一房 → 最终 Boss 击败 → 地图奖励宝箱出现 → 触碰箱子开启三轮三选一 → 全部领奖解锁出口 → 触碰目标出口 → 确认“带回结束”后通关结算 → 主城。

原型由配置固定为六房：`Combat → Chest → Combat → Npc → Combat → Boss`。每个房间只生成一次计划，恢复与重开使用同一房间身份和敌人槽位。房间顺序、内容、奖励和可调数值走 Excel，当前配置共 38 表，`ConfigVersion = v3-room-prototype-2`，不另建旧版配置集。

### 2.2 房间完成条件

| 类型 | 内容与推进 | 续关 |
| --- | --- | --- |
| Combat | 清除本房敌人后开放上方出口，触碰出口自动打开推进窗口 | 未完成时重建全部敌人；已发奖槽位不重复发奖 |
| Chest | 触碰未领取宝箱自动打开并暂停，领取事实与获得物品一起确认；完成后可继续 | 返回本房，不重发已领取物品 |
| Npc | 触碰 NPC 自动打开交易窗口并暂停，关闭后可继续向出口推进 | 暂离后的续关直接进入下一房 |
| Boss | 击败后出现地图宝箱，触碰开启原三轮三选一；全领只解锁出口，目标出口弹“带回结束 / 留在本房”，确认才通关 | 未击败时重建敌人；已击败后的存活检查点保留当前房、免费继续且不重生 Boss、不自动开窗 |

已完成房间不能回头重刷。宝箱领取中、商人购买中及未确认奖励等事务必须先完成保存确认或进入明确可重试状态，不能通过关闭窗口绕过门禁。

### 2.3 表现与操作

房间呈长条竖向布局，玩家从下方向上方推进。顶部 HUD 展示房间序号/总数、类型、剩余目标与出口状态，并展示永久等级、经验和技能点。总览展示房间预览及永久技能升级。

删除大小地图、地图选点和自动导航入口，保留移动与自动近战。NPC、未领取宝箱及已开放出口采用触碰自动开窗并暂停，主界面不保留互动按钮或 E/Tab 交互步骤。关闭 NPC 或出口窗口后，必须先离开对应触碰范围，再进入才能重开；原地不反复弹窗。普通宝箱领完后不再触发。Page/Modal、安全区、1080×1920 参考尺寸及横竖屏适配继续沿用，本轮横竖屏图形 2/2 通过，具体画面与布局检查范围见 6.4。

摇杆超过死区后的有效输入统一按角色配置移动速度移动，只使用输入方向，不以偏移幅度降低速度；死区内或松开停止，碰撞和战斗属性修正仍由 ECS 决定。Boss 奖励窗口允许关闭，离开宝箱触碰范围后重触继续未完成轮次，原冻结候选和已领取物品保持不变。普通已领取宝箱、Boss 已全部领奖宝箱均不再触发。

## 3 永久成长与物品归属

### 3.1 永久成长

所有击杀经验即时记入永久角色经验。升级与技能点通过同一活动局的进度账本确认，终局只展示本局已获得经验，不能再次发放同一批经验。死亡、放弃、广告撤离及房间重开均不回滚已经确认的永久成长。

当前技能点升级 `power`、`vitality`、`agility`，升级后更新玩家战斗属性。旧 Rogue 随机三选一及其窗口、入口、配置和专属测试已由新成长流程替代。Boss 装备/收藏奖励继续使用独立领奖流程。

[十六项核心属性方案](../v2/属性系统分析与完善方案.md)仍为后续方案；本轮不代表完整技能池、学习位置、进化或十六项属性统一计算已经实现。

### 3.2 固定装备与关卡背包

| 资产 | 局内使用 | 暂离与终局 |
| --- | --- | --- |
| 固定携入装备 | 入场时冻结，不能在关卡内穿脱或更换 | 活动局托管；任何终局均归还，不计广告名额 |
| 关卡背包 | 所有获得、掉落领取、奖励和购入物品只进此处，不能局内装备 | 暂离保留；通关全带回，广告仅带回所选，死亡确认/放弃全丢此背包 |
| 永久等级与技能 | 击杀与点数升级即时生效 | 始终保留已确认成长 |

关卡背包详情可以比较固定装备属性，但要说明回城并结束本局后才可装备。不能将背包物品标为本局已穿戴，也不能把固定装备复制为广告候选。收藏按实际入库登记，成就属性不重复发放。

## 4 暂离、恢复与费用

### 4.1 玩家保留，房间重建

暂离保留同一 `RunId`、当前房间、背包、固定装备、永久成长和已经发生的消耗。恢复玩家 HP 与自身状态使用最新已确认业务检查点，不恢复旧世界全部敌人、飞弹或地面战斗瞬态。

未清 Combat 或未击败 Boss 的房间重建敌人；用稳定房间与槽位身份记录 `RewardedSlotIds`，已获经验或物品的敌人再次击杀不重复发奖。重开不把玩家退回房间入口时的收益与消耗状态。已确认宝箱领取、NPC 售出和购买事实继续保留。

Boss 已击败后，未开箱、部分领奖、全领未退出的存活检查点都回到当前 Boss 房，不重生 Boss、不自动弹领奖或结算窗口；等待玩家触碰箱子或已解锁出口。未开箱不提前入包，部分领取保留冻结候选与已领事实，全领仅表示出口开放，不表示已经通关。

死亡待选必须保持死亡门禁；暂离后继续不能免费满血或跳过复活/退出选择。具体交易与恢复顺序见[房间进度与结算方案](房间进度与结算方案.md)。

### 4.2 主城隔离

暂停的“暂离返城”保留活动局，不执行失败结算。挂起期间锁定仓库、局外交易与换装，主城提供“继续本局”。需要重新整备时先结束本局，不能让主城和活动局同时持有同一装备或重复支出资金。

### 4.3 体力

| 操作 | 原型费用 |
| --- | --- |
| 首次开始 | 只扣入场费 10，第一房不另收费 |
| 进入后续每个新房 | 1 |
| 未清 Combat / 未击败 Boss 的存活续关 | 1 |
| Boss 已击败，未开箱 / 部分领奖 / 全领未退出的存活检查点 | 0，保留当前房，不重生 Boss、不自动弹窗 |
| 死亡待选续关，包括已击败 Boss | 1，保留死亡状态，不回满血 |
| Chest 续关 | 0 |
| Npc 续关 | 直接进入下一房并扣 1 |

费用来自配置，Home 与出口使用实际所需费用，余额不足时阻止动作。扣费依同一入房流水确认，保存重试不能重复扣费。暂离本身不额外收费。

## 5 死亡、广告与唯一终局

| 操作 | 玩家与房间 | 物品与成长 |
| --- | --- | --- |
| 死亡广告复活 | 原地满血，不限次数，保留当前进度 | 固定装备、关卡背包与永久成长保留 |
| 暂离 | 保留活动局，继续时按房间类型恢复并计费 | 不结算，保留托管与背包 |
| 死亡确认/主动放弃 | 形成唯一终局并返城 | 只丢关卡背包，归还固定装备，永久成长保留 |
| 广告撤离 | 暂停或死亡待选可请求，完成后弹关卡背包选择 | 选择 0..3 件实例保留，其余关卡背包损失；固定装备始终归还 |
| 最终 Boss 全部领奖 | 仅解锁目标出口，仍保留活动局 | 不提前入库或产生 Completed |
| 最终出口确认“带回结束” | 创建唯一 Completed 并结算；“留在本房”只关闭窗口 | 带回全部关卡背包并归还固定装备，永久成长不重复发放 |

广告成功仅授予本局选物授权；玩家最终确认后才形成终局。候选仅为关卡背包，数量不足三件可全选，也能取消勾选至零。关闭选物返回原 Pause/DeathChoice，授权保留，再次打开不重复广告。失败或取消不改变物品。

当前广告使用模拟提供者。真实 SDK 的有效完成回调、失败、取消与重复回调仍须平台实测，不能把请求广告当作完成。

## 6 决策状态与剩余边界

| 决策 | 本轮结论 |
| --- | --- |
| D1 成长归属 | 已定：永久经验、等级和技能点；当前三项永久技能，无旧 Rogue 随机三选一 |
| D2 未完成房间 | 已定：保留玩家检查点与已获/已耗，敌人重建，稳定槽位去重发奖 |
| D3 携入与主城 | 已定：固定装备不可局内更换且始终归还；独立关卡背包；挂起锁仓库、局外交易与换装 |
| D4 广告选物 | 已定：Pause/DeathChoice 请求，完成后选关卡背包 0..3 件实例，固定装备不占数，授权可重开 |
| D5 房间与奖励 | 已定：原型六房；Boss 击败后箱子出现，触碰开启三轮三选一，可关闭后重触继续；全领解锁出口，确认带回才 Completed |
| D6 费用与复活 | 已定：首次仅 10、首房免费，后续新房 1；未清战斗续关 1、Chest 续关 0、NPC 续关推进并 1；Boss 已击败存活检查点各领取阶段均 0，死亡待选仍 1 且不回满血；死亡广告无限次原地满血 |
| D7 磁盘与历史数据 | 未定：磁盘恢复时机、旧活动局和历史数据迁移；当前保持 Memory，不读写删除旧磁盘档 |

Mobile、微信和 PC 目标、正式广告/付费/联网接入、设备预算、长时间运行和发布验收尚需单独落实。原型数值可经配置调整；待实施扩展不能写成现有能力。
