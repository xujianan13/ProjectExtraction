## 1 本轮范围

V3 基线已将 V2 多区域原位改为六房线性原型：`Combat → Chest → Combat → Npc → Combat → Boss`，同时完成永久击杀成长、固定出战装备、独立关卡背包、房间业务检查点、暂离续关、分房间体力收费、死亡复活、广告 0..3 件撤离、唯一终局与 UI。

以上为沿用基线。本轮新增范围：有效摇杆输入统一配置速度；最终 Boss 击败后地图出现宝箱，触碰后展示一批 3 件实际物品，一个领取按钮全部入包，窗口可关闭并在离开后重触继续；全领奖后经目标出口确认结算。已击败 Boss 的未开、已开未领、全领未退出存活检查点均免费回当前房，不重生 Boss、不自动开窗；死亡待选仍收费 1 且不回满血。当前配置版本为 `v3-room-prototype-3`。

本轮继续使用 Memory，未开启原有磁盘档，不执行自动迁移、清档或退款。正式广告/付费/联网/微信 SDK、完整技能池、十六项属性方案和目标设备发布验收不在已完成范围。

### 6.3 首次费用与触碰自动开窗调整

本节记录基线 `20c090e` 之后用户新确认的规则。6.1 中的 357/357、582/582、图形 2/2、34 张截图及两份布局保留为基线历史，不能用于本轮通过结论。
