## 1 本轮范围

V3 已将 V2 多区域原位改为六房线性原型：`Combat → Chest → Combat → Npc → Combat → Boss`。本轮同时改造永久击杀成长、固定出战装备、独立关卡背包、房间业务检查点、暂离续关、分房间体力收费、死亡复活、广告 0..3 件撤离、唯一终局与 UI。

本轮继续使用 Memory，未开启原有磁盘档，不执行自动迁移、清档或退款。正式广告/付费/联网/微信 SDK、完整技能池、十六项属性方案和目标设备发布验收不在已完成范围。

### 6.3 首次费用与触碰自动开窗调整

本节记录基线 `20c090e` 之后用户新确认的规则。6.1 中的 357/357、582/582、图形 2/2、34 张截图及两份布局保留为基线历史，不能用于本轮通过结论。

**已确认规则：**

- 首次开关卡只收配置 `EntryCost`（当前 10），首房不另扣 `RoomEntryCost`。后续新房 1、Combat/Boss 续关 1、Chest 续关 0、NPC 续关直接下一房并扣 1，最终全领奖检查点恢复 0；各事务仍须保存重试幂等。
- 触碰 NPC、未领取宝箱及已开放出口自动打开对应窗口并暂停战斗，主界面无互动按钮。关闭 NPC/出口窗口后原地不重弹，离开该触碰范围再进入才可重开；宝箱领取后不再触发。

**实现与配置：**

- `ProjectRunRecordRules.TryAdmit` 和 `RequiredEntryStamina` 只计算 `EntryCost`；首房准入流水仍预先确认为 1，重复保存或恢复不另扣费。旧活动记录中已经保存的实际扣费不改写，取消未运行准入仍按实际扣费退款。
- `ExpeditionRun.Interactions` 在完整战斗帧后检测新进入触碰范围的设施。触碰记录在关闭窗口后保留，离开范围再解除；已领取宝箱不再进入候选。NPC 访问、宝箱领取均先完成保存确认，再开放窗口；保存期间和窗口期间不推进战斗。
- `BattleHudWindow` 移除互动、切换目标及附近目标摘要，保留摇杆、背包、成长与暂停。实际窗口的关闭按钮继续释放各自暂停状态。
- 只修改 `config/excel/CfgGuide.xlsx` 的移动、探索和体力正文，使用已有配置占位符；没有修改其他源表或 schema。修改前后 `verify` 及修改后 `export` 均为 38 表通过，生成 JSON 与清单同步。仓库 README、AGENTS 和当前 V3 设计/恢复说明同步。
