## 已确认规则

1. 关卡按线性房间单向推进，原型配置为 `Combat → Chest → Combat → Npc → Combat → Boss` 六房。玩家从长条房间下方进入、向上方出口推进；删除大小地图、点选导航与旧个体定时复活。最终 Boss 的全部奖励领取完成后自动通关，带回全部关卡背包。
2. 所有击杀经验即时归永久角色等级，升级获得永久技能点。当前可用技能点升级 `power`、`vitality`、`agility`；移除旧 Rogue 随机三选一。十六项核心属性及统一计算方案仍未实施，参见 [V2 属性分析](../v2/属性系统分析与完善方案.md)。
3. 携入装备固定，关卡内不能更换，任何终局均归还。所有获得和购入物品只进入关卡背包；死亡确认或主动放弃只丢失关卡背包，已获得永久成长保留。
4. 未完成战斗房继续时，按检查点恢复玩家 HP 与自身状态，保留已经获得和消耗的收益；重建所有敌人。稳定敌人槽位记录是否已经发奖，重复击杀不重复获得经验或物品。宝箱领取、商品售出等业务事实保留，NPC 房续关直接进入下一房。
5. 暂离返回主城保留同一活动局。挂起期间锁定仓库、局外交易与换装，仍可继续本局；暂离本身不结算。
6. 死亡可观看广告原地满血复活，不限次数。暂停或死亡待选时可请求广告撤离；广告完成后打开关卡背包，选择 `0..3` 件物品实例带回，不足三件可以全选且允许取消勾选。出战装备始终保留，不占名额；关闭选物返回原选择界面，已获授权保留。广告失败或取消不改变物品。
7. 首次开始只消耗入场费 10 点体力，首房不另收费；后续每个新房消耗 1。怪物房与 Boss 房续关消耗 1，包括死亡待选状态；宝箱房续关免费，NPC 房续关直接进入下一房并消耗 1。最终 Boss 已全部领奖、仅待补办唯一通关的检查点恢复免费。数值来自配置。
8. 触碰 NPC、未领取宝箱或已开放出口自动打开对应窗口并暂停战斗，无主界面互动按钮。关闭 NPC/出口窗口后须先离开触碰范围，再进入才能重开；站在原地不重复弹窗。宝箱领取后不再触发。

完整恢复与结算语义见[房间进度与结算方案](房间进度与结算方案.md)。当前配置共 38 表，六房顺序是可调原型，不是完整内容量或平衡验收。

## 尚待处理

- 磁盘后端恢复、文件吞吐、跨启动及进程终止矩阵独立验收；Memory 结果不能代表持久化通过。
- 旧活动局和历史数据的迁移策略另行决定，不自动清档、迁移或退款。
- 正式广告与平台接入、Mobile/微信/PC 设备性能、发布构建和长时间运行仍需实际验证。
- 完整技能池、技能进化与十六项属性方案未因本轮永久成长接入而完成。

## 工程边界与验证状态

Unity 2022.3.62f2；Mobile、微信小游戏优先并适配 PC，默认竖屏、兼容横屏。`GameLogic` 承担项目玩法，`GameFramework` 保持通用；正式内容与参数以 `config/excel` 为唯一源。ECS 决定战斗事实，动画和 UI 读取快照或事件。

工程只维护一套有效实现，按 V3 原位替换旧职责，不恢复 V1 代码或维护 V2/V3 双轨运行。三类武器、四个普通技能、装备词条、宝箱展示、商人、收藏及框架能力按[承接清单](文档承接清单.md)复用。

基线 `20c090e` 的 Prepare、38 表、EditMode **357/357**、Quick PlayMode **582/582**、横竖屏图形 **2/2** 通过，共 34 张截图和两份布局记录。最终领奖检查点中断后可在零体力下补办唯一通关，不新增房间收费。本轮首次费用与触碰开窗调整另行通过 Prepare、38 表、定向 EditMode **49/49**、Quick PlayMode **584/584**、横竖屏 **2/2**（36 张截图、两份布局）；实际命令、失败修复和限制见[实施计划与验收](实施计划与验收.md)。V2 实测仍见 [V2 实现记录](../v2/多区域玩法实现与验收.md)，不计为 V3 通过。
