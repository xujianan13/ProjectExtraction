## 已确认规则

1. 关卡按线性房间单向推进，原型配置为 `Combat → Chest → Combat → Npc → Combat → Boss` 六房。玩家从长条房间下方进入、向上方出口推进；删除大小地图、点选导航与旧个体定时复活。最终 Boss 击败后地图上出现奖励宝箱，触碰才开启现有三轮三选一。全部领奖只解锁最终出口，走到目标出口弹结算框，确认“带回结束”才产生 `Completed` 并带回全部关卡背包；选择“留在本房”不结算。
2. 所有击杀经验即时归永久角色等级，升级获得永久技能点。当前可用技能点升级 `power`、`vitality`、`agility`；移除旧 Rogue 随机三选一。十六项核心属性及统一计算方案仍未实施，参见 [V2 属性分析](../v2/属性系统分析与完善方案.md)。
3. 携入装备固定，关卡内不能更换，任何终局均归还。所有获得和购入物品只进入关卡背包；死亡确认或主动放弃只丢失关卡背包，已获得永久成长保留。
4. 未清怪物房或未击败 Boss 的续关，按检查点恢复玩家 HP 与自身状态，保留已经获得和消耗的收益并重建敌人。稳定敌人槽位记录是否已经发奖，重复击杀不重复获得经验或物品。Boss 已击败后，未开箱、部分领奖、全领未退出都保留当前 Boss 房且不重生 Boss、不自动弹窗，候选和已领事实保留。宝箱领取、商品售出等业务事实保留，NPC 房续关直接进入下一房。
5. 暂离返回主城保留同一活动局。挂起期间锁定仓库、局外交易与换装，仍可继续本局；暂离本身不结算。
6. 死亡可观看广告原地满血复活，不限次数。暂停或死亡待选时可请求广告撤离；广告完成后打开关卡背包，选择 `0..3` 件物品实例带回，不足三件可以全选且允许取消勾选。出战装备始终保留，不占名额；关闭选物返回原选择界面，已获授权保留。广告失败或取消不改变物品。
7. 首次开始只消耗入场费 10 点体力，首房不另收费；后续每个新房消耗 1。未清怪物房与未击败 Boss 的续关消耗 1；宝箱房续关免费，NPC 房续关直接进入下一房并消耗 1。Boss 已击败后的三种领取/待退出阶段，存活检查点均可零体力恢复；死亡待选仍消耗 1，保留死亡门禁且不回满血。数值来自配置。
8. 触碰 NPC、未领取宝箱或已开放出口自动打开对应窗口并暂停战斗，无主界面互动按钮。NPC/出口及未领完 Boss 宝箱窗口关闭后须先离开触碰范围，再进入才能重开；站在原地不重复弹窗，重开继续原冻结候选。已领完宝箱不再触发。
9. 摇杆超过死区后的有效输入只决定方向，统一按角色配置移动速度移动，不随偏移幅度减速；松开或回到死区内停止。移动仍由 ECS 处理碰撞和战斗属性修正。

完整恢复与结算语义见[房间进度与结算方案](房间进度与结算方案.md)。当前配置共 38 表，版本为 `v3-room-prototype-2`，六房顺序是可调原型，不是完整内容量或平衡验收。

## 尚待处理

- 磁盘后端恢复、文件吞吐、跨启动及进程终止矩阵独立验收；Memory 结果不能代表持久化通过。
- 旧活动局和历史数据的迁移策略另行决定，不自动清档、迁移或退款。
- 正式广告与平台接入、Mobile/微信/PC 设备性能、发布构建和长时间运行仍需实际验证。
- 完整技能池、技能进化与十六项属性方案未因本轮永久成长接入而完成。
