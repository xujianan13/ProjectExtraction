# 核心玩法设计

更新日期：2026-09-29。状态：已确认玩法方向与结算规则，细节待补充，尚未实现。

本文件记录用户当前确认的游戏规则，作为后续玩法开发入口。工程实现仍为 Minimal 空 Main/Home，实际工程状态见[项目基础接入验收](项目基础接入验收.md)。下文的待定项不能作为已批准需求直接实现。

## 定位与基础循环

项目采用 3D 第三人称俯视视角，以近战自动攻击、程序化房间探索、随机属性装备、技能物品和撤离收益组成核心循环。沿用 Mobile 与微信小游戏优先、兼顾 PC、默认竖屏兼容横屏的项目约束。

基础循环：局外恢复/领取体力、装配与购买 → 校验体力和等级后携装进入关卡 → 探索程序化房间 → 自动近战、打怪获得经验与战利品 → 进入撤离点或死亡 → 结算物品，成功撤离另获经验 → 经验自动升级，开放更高级装备、技能、关卡和局外商店购买资格。

## 已确认规则

### 近战与自动攻击

- 只保留近战武器，使用统一的一种基础攻击方式。
- 不同武器通过属性区别，包括攻击范围和附带技能等。
- 武器相同属性的数值可以随机；数值区间、分布及生成时机待后续配置设计。
- 角色自动攻击攻击范围内的目标。
- 自动索敌优先级、切换目标规则、攻击方向、攻击过程中能否移动及附带技能触发方式尚未确定。

### 关卡与房间

每局关卡由若干程序化生成的房间构成，房间结构参考用户提出的《以撒的结合》式房间探索。当前确定四种房间：

| 房间类型 | 主要内容 | 战利品来源 |
| --- | --- | --- |
| 小怪房 | 与普通怪物战斗 | 小怪可能掉落战利品 |
| Boss 房 | 与 Boss 战斗 | Boss 必掉战利品 |
| NPC 房 | NPC 商店购买 | 可购买战利品 |
| 战利品房 | 房间内直接生成奖励 | 直接刷出战利品 |

房间数量、连接方式、内部布局生成方式、房间类型比例及各类房间是否必定出现尚未确定。

### 撤离与小地图

- 房间中会随机刷出撤离点。
- 撤离点支持默认出现，以及满足条件后出现；战斗房间清怪后刷出属于已提出的条件形式。
- 角色进入撤离点或角色死亡时，当局游戏结束。
- 小地图采用用户提出的《地下城与勇士》式房间信息展示。
- 小地图标注房间信息，**不标注撤离点**。

撤离点数量、生成概率、具体触发条件、是否保证存在可达撤离点，以及小地图的探索显示规则尚未确定。

### 成长与战利品

- 每次成功撤离和打怪均产生角色经验；两类经验来源分别记录，不能在单局结算时重复发放。
- 经验达到门槛后自动提升等级，无需手动确认升级。
- 角色等级用于高级装备穿戴、技能装配、高等级关卡解锁和局外商店购买资格；具体等级门槛后续配置。
- 穿戴/装配门槛不自动等于拾取、持有或携出限制；低等级持有高级物品的限制未获确认，不能擅自添加。
- 战利品包括装备、技能等物品。
- **技能属于特殊物品，可以带出关卡。**
- 技能的持有、装备、使用与效果生效方式尚未确定；“技能物品可带出”目前只确认物品的携出规则。
- 打怪经验按击杀、伤害或参与计奖的口径、局内经验/等级的生效时机、死亡时是否保留本局打怪经验尚未确定；死亡本身不新增已确认来源之外的经验奖励。
- 两类经验奖励数值、升级曲线，以及装备、技能、关卡、局外商店的等级门槛后续配置。

### 局外体力与商店

体力用于控制玩家进入关卡的节奏，独立于战斗生命值和角色经验，规则与参数如下：

| 项目 | 当前规则或暂定值 |
| --- | --- |
| 体力上限 | 暂定 100 点 |
| 单局消耗 | 每局 10 点；扣除时点与加载失败返还待定 |
| 自然恢复 | 每 6 分钟增加 1 点 |
| 每日重置 | 每天早上 5 点重置到 100 点 |
| 定时补给 | 每天 12 点、18 点、24 点，玩家可分别手动领取 40 点；24 点即次日 0 点 |

定时领取是玩家领取行为，不等于到点自动到账。领取窗口、是否补领、超过上限如何处理、离线恢复、游戏日时区及时间来源尚未确定。详细责任与验收见[M09 体力与每日补给](模块设计/M09-体力与每日补给.md)。

新增局外商店购买，并受角色等级约束。已有 NPC 房商店继续保留；两类商店是否共用商品池、货币和库存另行设计，不能将新增局外商店误当作取消 NPC 房。

### 结算与安全箱

| 当局结束方式 | 入场装备与本局战利品 | 技能物品 | 安全箱内物品 |
| --- | --- | --- | --- |
| 正常撤离 | 当前持有的物品全部带回；入场装备保留，无结算挑选件数限制 | 随持有物品带回 | 带回 |
| 角色死亡 | 安全箱外全部丢失，包括入场装备与本局获取的战利品 | 安全箱外丢失，箱内保留 | 保留并带出 |

- 安全箱是死亡结算时的物品保护容器，箱内入场物品与本局战利品均按保护规则处理。
- 安全箱有容量限制，默认容量为 **X**，具体数值后续配置，不先填入固定值。
- 原先“正常撤离后选择 X 件带出”的方案已取消；目前的 X 只指安全箱默认容量。
- 普通背包容量、物品占用容量和堆叠方式另行确定。
- 本轮只确认装备和物品的死亡损失，不追加等级回退等惩罚规则。

## 相比前一版的变更

| 项目 | 当前决定 |
| --- | --- |
| 远程枪械与近战并存 | 改为仅近战 |
| 手动射击、近战攻击按钮方案 | 基础攻击改为范围内自动攻击，其他操作细节待定 |
| 按武器类型设计不同攻击操作 | 改为统一基础攻击方式，以属性和附带技能形成差异 |
| 正常撤离挑选有限件数物品带出 | 改为全部持有物品携出 |
| 死亡损失 | 安全箱外的入场装备与本局战利品全部丢失 |
| 技能与带出关系 | 技能作为特殊物品，可携出；死亡遵守安全箱保护规则 |
| 经验来源与等级用途 | 增加打怪经验，经验自动升级；等级约束装备穿戴、技能装配、关卡准入和局外商店购买 |
| 局外节奏 | 增加体力上限、单局消耗、自然恢复、每日重置和三次定时补给 |
| 商店范围 | 增加局外商店，保留已确认的 NPC 房商店 |

此前讨论过的三选一奖励、临时强化以及建议的原型数量和时长，本轮尚未重新确认，不作为当前确定规则。技能物品不套用此前建议的“每局结束统一清空强化”规则；若后续加入独立的临时效果，需另行定义其生命周期。

| 优先事项 | 尚需明确的内容 |

| 安全箱使用 | 容量按件数或格数计算；物品占用和堆叠；何时允许存取；哪些物品可放入；箱内物品能否同时产生装备效果 |

| 程序化房间与撤离 | 房间生成边界；门和战斗封锁；撤离点生成时机、数量、可达性与触发确认方式 |
| 经济与成长 | 打怪经验计奖口径与死亡保留；经验生效时机及升级曲线；四类等级门槛；两类商店货币、商品和价格；装备全失后的再次出战方式 |
| 体力与补给 | 游戏日时区；领取窗口、补领及溢出；离线恢复；重置与自然恢复的边界顺序；扣费时点与失败返还 |
| 局内外衔接 | 普通背包和局外存储；物品装配；成功撤离、死亡与异常中断的结算边界 |
| 随机奖励选择 | 是否保留三选一，以及它与直接掉落装备、技能物品的关系 |
