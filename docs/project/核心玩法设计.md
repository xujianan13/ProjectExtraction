# 核心玩法设计

更新日期：2026-09-30。状态：已确认玩法方向与结算规则，细节待补充，尚未实现。

本文件记录用户当前确认的游戏规则，作为后续玩法开发入口。工程实现仍为 Minimal 空 Main/Home，实际工程状态见[项目基础接入验收](项目基础接入验收.md)。下文的待定项不能作为已批准需求直接实现。

## 定位与基础循环

项目采用 3D 第三人称俯视视角，以近战自动攻击、程序化地图探索、随机属性装备、局外技能成长和撤离收益组成核心循环。沿用 Mobile 与微信小游戏优先、兼顾 PC、默认竖屏兼容横屏的项目约束。

基础循环：局外恢复/领取体力、整理装备、提升技能与购买 → 校验体力和等级后携装进入关卡 → 探索相连的程序化地图 → 自动近战、打怪获得经验与战利品 → 进入撤离点或死亡 → 结算物品，成功撤离另获经验 → 经验自动升级并获得技能点，开放更高级装备、关卡和局外商店购买资格。

## 已确认规则

### 玩家主要属性与货币

玩家主要属性统一为 **等级、经验、体力、金币、钻石**。

| 属性 | 当前定位与用途 |
| --- | --- |
| 等级 | 由经验自动提升，控制高级装备穿戴、关卡解锁和局外购买资格；升级获得技能点 |
| 经验 | 打怪与成功撤离产生，用于自动升级 |
| 体力 | 控制出战节奏，按本文件体力规则消耗、恢复、重置和领取 |
| 金币 | 常规货币，用于购买物品等常规消耗；出售战利品可获得金币 |
| 钻石 | 独立的高级货币体系，用于单独定义的高级消费；具体来源与消费项目待定 |

金币和钻石各自定义产出、消费和价格。消费项目使用明确的币种，余额不足时该笔交易失败。

战利品出售属于玩家主动交易，不改变正常撤离全部携出的规则。出售地点、可售物品和价格尚待细化；金币/钻石与死亡结算的关系需另行明确，不能直接套用安全箱外物品丢失规则。

技能点与技能等级属于局外成长，不是第六项顶部主要属性，也不是金币、钻石之外的支付货币。局外 Home 顶部展示五项主要属性，底部提供仓库和技能两个入口；技能点在技能面板显示。具体布局见[主界面设计](主界面设计.md)，技能规则见[技能成长设计](技能成长设计.md)。

数据口径、钱包与物品边界、购买和出售流程、UI 及验收见[玩家主要属性与货币设计](玩家主要属性与货币设计.md)。其中建议方案不等于已确认的钻石来源或具体高级消费项目。

### 近战与自动攻击

- 只保留近战武器，使用统一的一种基础攻击方式。
- 不同武器通过属性区别，包括攻击范围和武器附加效果等；武器附加效果与角色技能的关系待定。
- 武器相同属性的数值可以随机；数值区间、分布及生成时机待后续配置设计。
- 角色自动攻击攻击范围内的目标。
- 自动索敌优先级、切换目标规则、攻击方向、攻击过程中能否移动及武器附加效果触发方式尚未确定。

### ECS 战斗框架

本轮确定战斗使用 ECS，由技能、飞弹、Buff 和底层效果组成。技能使用时间轴，例如第 0 帧播放动画、第 5 帧前冲、第 10 帧产生伤害判定；节点上的动画、位移、伤害、添加 Buff 和发射飞弹均由效果组合。

飞弹具有实体身份，参数支持直线、抛物线和立即在目标处出现，以及目标锁定；命中产生效果。Buff 支持叠加、替换、重置等添加方式，默认按间隔生效并按时长结束，生命周期事件也触发效果。

详细合同见[战斗框架设计](战斗框架设计.md)及技能、飞弹、Buff 分册。60Hz 逻辑帧、具体执行阶段、目标筛选、默认叠加键和跨图处理为首版建议，不是已实现 API 或最终数值。普通自动近战作为战斗技能复用时间轴，使用 CombatSkillId；局外成长技能仍由技能点提升，使用 SkillId，不改变近战武器和基础操作规则。

### 关卡与地图

每局关卡由随机生成的若干地图构成，地图之间连通。本轮暂定：不必完成当前地图即可沿已有出口前往相连地图，未清怪、未击败 Boss 或未拿完奖励都不锁住跨图通道。

首版建议把地图对应到原有房间节点，内部沿用 RoomId/RoomGraph，不另嵌套一层房间图。地图内容沿用四种类型：

| 房间类型 | 主要内容 | 战利品来源 |
| --- | --- | --- |
| 小怪房 | 与普通怪物战斗 | 小怪可能掉落战利品 |
| Boss 房 | 与 Boss 战斗 | Boss 必掉战利品 |
| NPC 房 | NPC 商店购买 | 可购买战利品 |
| 战利品房 | 房间内直接生成奖励 | 直接刷出战利品 |

地图具体数量、连接形态、内部布局、类型比例及各类型是否必出仍待正式配置。详细建议见[关卡与地图设计](关卡与地图设计.md)：主路、支路与环路、自由换图、回访状态和撤离路线。文中的 8～12 张地图、模板组合、撤离保底和探索揭示属于本次建议，不能视为已确认数值。

跨图通行与清怪后显现撤离点分别判断；换图不会结束当局、追加一次入场体力消耗、发放撤离经验或把物品带回局外。

### 撤离与小地图

- 地图中会随机刷出撤离点。
- 撤离点支持默认出现，以及满足条件后出现；战斗房间清怪后刷出属于已提出的条件形式。
- 角色进入撤离点或角色死亡时，当局游戏结束。
- 小地图采用用户提出的《地下城与勇士》式房间信息展示。
- 小地图标注地图节点（原房间）信息，**不标注撤离点**。

撤离点数量、生成概率、具体触发条件、是否保证存在可达撤离点，以及小地图的探索显示规则尚未确定。

### 成长与战利品

- 每次成功撤离和打怪均产生角色经验；两类经验来源分别记录，不能在单局结算时重复发放。
- 经验达到门槛后自动提升等级，无需手动确认升级。
- 角色等级用于高级装备穿戴、高等级关卡解锁和局外商店购买资格；三类等级门槛后续配置。等级不足不自动限制拾取、持有或携出高级装备。
- 角色升级获得技能点，获得数量后续配置；玩家在局外消耗技能点提升角色技能。技能定义与效果由 M05 配置，技能点、已学等级及升级交易由 M07 管理。
- 技能不是物品，不参与掉落、购买、出售、背包、安全箱、携出或装备装配。已保存的技能等级与剩余技能点不随死亡时的物品损失清除。
- 技能点只随已确认生效的等级提升发放；一次经验变化跨越多级时逐级计算并去重，保存失败不得提前确认点数。技能每级点数、升级成本、触发形式和洗点规则待定。
- 打怪经验按击杀、伤害或参与计奖的口径、局内经验/等级的生效时机、死亡时是否保留本局打怪经验尚未确定；死亡本身不新增经验来源。
- 两类经验奖励数值、升级曲线以及三类等级门槛后续配置。

### 局外体力与商店

体力用于控制玩家进入关卡的节奏，独立于战斗生命值和角色经验，规则与参数如下：

| 项目 | 当前规则或暂定值 |
| --- | --- |
| 体力上限 | 暂定 100 点 |
| 单局消耗 | 每局 10 点；扣除时点与加载失败返还待定 |
| 自然恢复 | 每 6 分钟增加 1 点 |
| 每日重置 | 每天早上 5 点重置到 100 点 |
| 定时补给 | 每天 12 点、18 点、24 点，玩家可分别手动领取 40 点；24 点即次日 0 点 |

定时领取是玩家领取行为，不等于到点自动到账。领取窗口、是否补领、超过上限如何处理、离线恢复、游戏日时区及时间来源尚未确定。详细责任与验收见[M09 体力与每日补给](模块设计/M09-体力与每日补给.md)。

新增局外商店购买，并受角色等级约束。已有 NPC 房商店继续保留；两类商店商品池和库存是否共用、NPC 房使用何种货币及能否动用局外余额另行设计，不能将新增局外商店误当作取消 NPC 房。

### 结算与安全箱

| 当局结束方式 | 入场装备与本局战利品 | 安全箱内物品 | 已保存技能成长 |
| --- | --- | --- | --- |
| 正常撤离 | 当前持有的物品全部带回；入场装备保留，无结算挑选件数限制 | 带回 | 已学技能等级与剩余技能点保留 |
| 角色死亡 | 安全箱外全部丢失，包括入场装备与本局获取的战利品 | 保留并带出 | 已学技能等级与剩余技能点保留 |

- 安全箱是死亡结算时的物品保护容器，箱内入场物品与本局战利品均按保护规则处理。
- 安全箱有容量限制，默认容量为 **X**，具体数值后续配置，不先填入固定值。
- 原先“正常撤离后选择 X 件带出”的方案已取消；目前的 X 只指安全箱默认容量。
- 普通背包容量、物品占用容量和堆叠方式另行确定。
- 本轮只确认装备和物品的死亡损失，不追加等级回退等惩罚规则。

## 相比前一版的变更

| 项目 | 当前决定 |
| --- | --- |
| 远程枪械与近战并存 | 改为仅近战 |
| 手动射击、近战攻击按钮方案 | 基础攻击改为范围内自动攻击，其他操作细节待定 |
| 按武器类型设计不同攻击操作 | 改为统一基础攻击方式，以属性和武器附加效果形成差异 |
| 正常撤离挑选有限件数物品带出 | 改为全部持有物品携出 |
| 死亡损失 | 安全箱外的入场装备与本局战利品全部丢失 |
| 关卡结构与通行 | 随机生成的若干地图彼此连通；暂定不必完成当前地图即可前往相连地图 |
| 技能规则 | 原技能物品与携出方案已取消；角色升级获技能点，并在局外提升技能 |
| 经验来源与等级用途 | 增加打怪经验，经验自动升级并发技能点；等级约束装备穿戴、关卡准入和局外商店购买 |
| 局外节奏 | 增加体力上限、单局消耗、自然恢复、每日重置和三次定时补给 |
| 商店范围 | 增加局外商店，保留已确认的 NPC 房商店 |
| 主要属性与货币 | 明确等级、经验、体力、金币、钻石五项；增加战利品出售换金币与常规金币消费，钻石作为独立的高级货币 |

此前讨论过的三选一奖励、临时强化以及建议的原型数量和时长，本轮尚未重新确认，不作为当前确定规则。旧版技能物品方案已经取消；若后续加入独立的临时效果，需另行定义其生命周期。

## 落地前需要补充的规则

| 优先事项 | 尚需明确的内容 |
| --- | --- |
| 安全箱使用 | 容量按件数或格数计算；物品占用和堆叠；何时允许存取；哪些物品可放入；箱内物品能否同时产生装备效果 |
| 技能成长 | 每级技能点数量、技能升级成本与条件、主动或自动触发、洗点规则；与武器附加效果的关系 |
| 自动战斗 | 依战斗设计验证目标选择、命中形状、移动与攻击关系；确认固定时序、飞弹与 Buff 默认策略和性能预算 |
| 程序化地图与撤离 | 地图数量、结构与内部布局；自由换图的入口、回访状态和失败恢复；撤离点生成时机、数量、保底建议与触发方式；小地图揭示范围 |
| 经济与成长 | 打怪经验计奖口径与死亡保留；经验生效时机及升级曲线；三类等级门槛；升级技能点；两类商店商品与价格；出售地点及可售规则；钻石来源/用途；钱包死亡政策；装备全失后的再次出战方式 |
| 体力与补给 | 游戏日时区；领取窗口、补领及溢出；离线恢复；重置与自然恢复的边界顺序；扣费时点与失败返还 |
| 局内外衔接 | 普通背包和局外存储；物品装配；成功撤离、死亡与异常中断的结算边界 |
| 随机奖励选择 | 是否保留三选一，以及它与直接掉落装备的关系；角色技能不进入随机物品奖励 |
