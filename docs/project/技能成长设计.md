## 已确认的玩法

角色通过打怪与成功撤离获得经验，达到等级门槛后自动升级；升级获得技能点。玩家在局外技能界面消耗技能点提升角色技能。技能升级后的等级作为局外成长记录保存，下一局按已保存等级计算效果。

角色技能不是高级装备、特殊物品或可携出的战利品。它没有 `ItemInstanceId`、背包位置、安全箱格位、装备槽、出售或掉落行为，也不通过商店购买物品流程获得。正常撤离与死亡只按既有规则结算物品；安全箱外装备和战利品丢失，不清除已经保存的技能等级和技能点。

等级的已确认用途为高级装备穿戴、关卡解锁、局外购买资格，以及升级授予技能点。无需再设计“高级技能装配资格”。装备穿戴门槛不自动禁止低等级玩家拾取、持有或携出装备。

主要属性保持**等级、经验、体力、金币、钻石**五项。技能点是局外成长资源，在技能面板显示余额，并可在主界面底部技能按钮显示角标；它不加入顶部五项主要属性，也不属于金币/钻石钱包。技能点升级成本与金币、钻石消费相互独立；是否另需其他资源尚未确认。

## 模块与数据归属

| 内容 | 归属与要求 |
| --- | --- |
| 有效经验、等级和升级奖励 | M07 权威管理；经验来源去重，只有确认生效的等级才授技能点 |
| `SkillProgressionState` | M07 持有和持久化，可用技能点、各 `SkillId` 的等级及奖励/交易去重记录 |
| `SkillDefinition` | M05 提供角色技能定义、各等级效果、成本及未来确定的上限和前置配置；M07 读取配置 |
| 技能升级 | M07 在局外验证并将点数扣除、技能等级提升与 `TransactionId` 原子保存 |
| 效果计算 | M05 读取 M07 已保存技能等级，向战斗模块提供结果；触发模式仍待确定 |
| 展示 | M08 绘制技能面板和技能按钮角标，从 M07 查询余额与等级，不直接修改成长状态 |
| 武器附加效果 | M05 随武器定义和装备状态计算，与角色技能成长分开；具体保留及叠加规则待定 |

这里的类型名是拟议契约，不代表现有实现。

## 从经验到技能点

1. 打怪经验与成功撤离经验分别识别来源并去重；成功撤离结算不能重发已经计奖的打怪经验。
2. 以已确认生效经验计算旧等级和新等级。一次经验跨越多级时，逐个新等级查询奖励配置并授点，每个等级仅授一次。
3. 经验、等级结果、技能点奖励及去重身份一起提交。提交失败不发布已保存等级或技能点；同一事实重试返回已提交结果。
4. 局内经验何时生效、死亡时是否保留打怪经验均待定。未确定保留的临时经验不提前产生永久技能点。

每级授点数量、初始技能点、等级曲线和满级处理均待配置，不先假定每级获得 1 点。

## 局外升级

1. 玩家在局外选择技能下一等级，界面展示当前等级、下一等级效果、所需技能点及可用点数。
2. M07 校验处于局外、技能定义存在、当前等级匹配、目标等级合法、未超过上限、满足配置前置及点数足额；扣除后不得出现负值。
3. M07 把技能点扣除、目标技能等级提升及 `TransactionId` 完成记录作为同一次持久化变化。相同标识重试不能重复扣点；保存失败维持原状态。
4. 保存确认后，M08 更新面板和按钮角标，M05 在后续效果计算中使用新等级。局内不允许消费点数提升技能。

升级成本、技能等级上限、技能前置、是否能重置或洗点及重置代价仍待定。界面草图中的技能名称、点数与等级仅为布局示例，不是正式配置。

## 武器与角色技能

现有武器差异中的“附带技能”改称**武器附加效果**，以区分角色技能成长。武器仍可通过攻击范围、随机属性和武器附加效果形成差异，所有武器共用统一基础攻击。武器附加效果是否全部保留、怎样触发、与角色技能是否叠加及先后顺序，后续单独确定；不能因为角色技能改为局外成长而默默移除这些差异。

## 待确认清单

- 技能列表、各技能效果、每级技能点奖励、升级成本、上限和前置。
- 技能属于主动、自动还是被动，以及与近战自动攻击的交互、冷却和效果叠加。
- 技能重置/洗点是否存在、返还范围与代价。
- 局内经验生效时机与死亡保留政策；只有确认生效等级才能永久授点。
- 武器附加效果的保留范围、触发与角色技能的组合规则。
