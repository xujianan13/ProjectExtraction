# 局外金币商店首版实现

更新日期：2026-10-03。第六阶段补齐局外购买和死亡后补给循环。本文区分当前实现、首版可调配置和后续工作。

## 玩家流程

Home 底部新增「商店」，与仓库、技能并列。商店使用项目既有 uGUI 模态窗口和安全区布局，支持全部、武器、装备、物品筛选；商品列表和属性详情分别滚动。列表展示金币价格、购买等级和剩余数量，详情使用真实物品属性与品质颜色。等级不足、金币不足或售罄时可以查看，不能购买。

购买成功后物品进入仓库且不自动穿戴；点击「前往仓库」关闭商店，再打开仓库完成装备。出战仍扣除既有体力费用。死亡后安全箱外装备按原规则丢失，玩家可以使用保留的局外金币补购常备装备，再次入场。无金币时沿用现有空手出战能力，不新增免费装备领取或强制购买门槛。

金币不足直接拒绝交易，钻石余额不参与价格计算或补差。局内 NPC 商店仍使用原来的单局报价、暂停和结算逻辑。

## 配置和商品

新增唯一源表 [CfgHomeShop.xlsx](../../config/excel/CfgHomeShop.xlsx)，当前项目共 28 张内容表。新增商品必须通过 Excel 导出，启动时由 ProjectHomeShopConfig 校验；缺表、无效引用、非法库存和等级门槛会阻止项目初始化。

| 字段 | 含义 |
| --- | --- |
| ID / Name / SortOrder | 稳定商品身份、展示名称与排序；同排序按 ID 排列 |
| DefinitionId / Quality / ItemLevel | 装备模板、固定品质与物品等级 |
| RequiredLevel / PriceGold | 购买等级门槛和金币价格；门槛不得低于物品等级 |
| StockLimit | -1 为常备供货，正整数为当前存档的累计购买上限 |
| ItemSeed | 固定属性生成种子；预览和交付使用相同模板、等级、品质与种子 |

首版商品为 1 级普通武器/护甲（20/28 金币，常备）、3 级精良武器/护甲（各 60 金币，各限购 2 件）、6 级优秀武器/护甲（各 100 金币，各限购 1 件）。这些是可调原型数值。初始 50 金币可购买一套基础装备。

限购是**存档累计次数**，不在死亡、重新打开商店、重新启动或每日重置时补货。首版没有每日刷新；后续如需周期库存，须增加独立周期身份并设计旧记录迁移。

固定商品每份属性一致，但每次购买的物品实例 ID 不同。普通掉落仍按既有规则随机。启动校验要求购买价格高于对应模板在该等级与品质下的最大出售价格，避免直接买卖套利。已经购买的实例保存冻结属性，后续改表不会重抽旧物品；改商品配置仅影响之后的报价。

## 保存与去重

ProjectSession 是购买的唯一持久化入口。购买时校验局外可编辑状态、报价修订号、等级、金币与库存，再在独立候选中同时变更金币、物品、累计购买记录和购买修订号。保存确认之前，界面和其他逻辑仍读取原已提交状态。

每次成功购买递增持久化的 HomeShopPurchaseRevision。旧报价或重复提交使用旧修订号时被拒绝；购买另一个商品也会使此前报价过期。运行期间不热重载配置，因此报价不会在同一会话里随配置切换。

保存失败后保留原候选，商店显示「重试保存」，并锁住新购买。重试沿用原物品 ID、属性、扣款和库存变更；既有 Home 保存重试入口也可继续原事务。退出商店不会取消已经提交的保存操作。

存档 schema 保持 3，新增 HomeShopPurchaseRevision 和 HomeShopPurchases。旧存档缺少字段时按 0 和空列表读取；复制存档时深拷贝购买记录。商品下架后历史计数仍能读取，不因配置中缺少旧商品而废弃存档。商品 ID 不应复用于不同限购商品。
