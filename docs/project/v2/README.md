## 当前设计

[多区域探索与成长奖励整体设计](多区域探索与成长奖励整体设计.md)是玩法开发总入口：第 1 节记录已确认方向，第 12 节列出阶段计划，第 13 节集中记录待定项。建议、原型示例和待定事项不能当作已经批准的正式规则。

- 每关包含多个区域，每个区域为单张可探索地图；入关消耗一次体力，进入后续区域不再收费。
- 普通怪与精英随机按组生成，刷怪进度达到阈值触发技能三选一，精英贡献更多进度。
- 关卡开启时确定各区域 Boss 及地图资源；每区首次生成时固定独立随机组合，保存 NPC、宝箱、怪物及关联状态，非正常退出后继续同一局。
- 普通怪死亡后 3 分钟、精英 5 分钟复活，使用区域有效时间，暂停和离线不计时；参数可调，复活击杀继续贡献成长。
- 区域尾王与关卡 Boss 必出装备或收藏品三选一，与技能池分开；关卡 Boss 支持多次选择，具体时机和数量待定。
- 玩家死亡后选择结算返回或看广告原地满血复活；每次死亡均可复活、不限次数，保留本局进度与物品，复活不重复扣体力。当前使用立即完成的模拟广告，正式平台 SDK 尚未接入。
- 成功结束带回全部当前持有物品，死亡确认结算或主动放弃全部损失，含入场装备、战利品、购入物、收藏品和卸下装备；广告复活继续保留全部物品。钱包与已保存成长沿用已有处理；收藏仅成功带回实际入库登记，重复可出售，成就属性只奖励一次。
- 右上角小地图点击后展开放大并暂停，标注精英、区域 Boss、NPC 和宝箱；点击地面或标记预览绕障路线，确认“前往”后自动移动，手动输入立即取消。尾王完成后可留在本区、结束或继续下一域，首版区域单向推进。
- 关卡开启时确定并告知最终 Boss；精英和 Boss 的弱点影响流派选择。
- Boss、宝箱和商人提供主题战利品与收藏品，收藏成就增加属性。
- 宝箱领取保存确认后自动弹出本次获得物品，默认展示首件详情并支持逐件查看；窗口期间暂停战斗，关闭后继续探索。

## 沿用的基础边界

以下基础方向在 v2 中继续有效；涉及新版区域、奖励、收藏和续关的细节，以整体设计及其待定项为准。

| 范围 | v2 基础边界 |
| --- | --- |
| 平台与操作 | 3D 俯视、近战自动基础攻击；Mobile、微信小游戏优先并适配 PC；默认竖屏、兼容横屏 |
| 长期成长 | 等级、经验、体力、金币、钻石；升级获得局外技能点，局外技能与本关技能三选一分别管理 |
| 物品与结算 | 装备与单一背包；成功结束携出全部当前持有物品，死亡确认结算/主动放弃全部损失，广告复活保留全部物品；仓库锁定仅防出售，收藏仅成功带回实际入库登记 |
| 货币与交易 | 金币用于常规消费与战利品出售，钻石独立管理；价格、等级和库存配置化，物品与钱包一致保存 |
| 战斗属性 | HP、攻击、防御、暴击值、暴击伤害、闪避、增伤、减伤；武器与护甲具有默认属性和随机词条 |
| 品质 | 普通、精良、优秀、史诗、传说、神器对应白、绿、蓝、紫、橙、红；具体公式与权重仍为可调配置 |
| 工程与界面 | 项目业务留在 GameLogic，通用框架不依赖玩法；Excel 为正式内容唯一源；主 UI 使用 Page，弹窗使用 Modal，并适配安全区 |

当前数据中的体力数值、普通/精英贡献 1/5 与阈值 20、Boss 1/3 轮及收藏成就属性均有明确的原型或待定数值边界，不因落地配置被确认为最终数值。上表为概要，细节见对应基础规范及实现记录；后续发现遗漏时修订当前规范，不直接恢复整篇旧文档的约束力。

## 实施顺序与替换要求

| 阶段 | 主要交付 | 旧实现处理 |
| --- | --- | --- |
| P1 | 刷怪进度、技能独立池与 HUD | 删除旧清房概率、保底调度和技能候选中的物品分支；其余奖励来源按待定项确定后切换 |
| P2 | Boss 地图绑定、首次生成固化、个体复活、大小地图及单区保存恢复 | 替换旧小房间连接图、节点投影和切换路径，删除旧专属配置测试与中断退款恢复路径 |
| P3 | 多区域及转换恢复、Boss 战利品多轮选择和终局恢复 | 替换单一 Boss 身份和旧自动主战利品路径，删除已被替代的流程与入口 |
| P4 | 弱点、探索内容及独立奖励池 | 按新内容契约整理敌人、箱子与商人，清理失效配置 |
| P5 | 收藏、成就和永久属性 | 建立当前数据契约，不为兼容 v1 保留旧运行分支 |
| P6 | 整关恢复加固、长时间保存及设备体验验收 | 核查已有恢复能力与设备成本，清除已无用途的过渡代码和资产 |
