## 1 本次实现范围

- 原地替换旧房间图、清房奖励和混合候选池，工程只保留 v2 区域流程，没有 v1 开关或备用运行分支。
- 开局冻结全部区域尾王、最终 Boss、地图身份和独立种子；每区首次进入时生成并保存怪群、精英、宝箱、商人及完整物品结果。
- 整关准入只扣一次体力，后续区域转换与异常继续不重新扣费。区域完成后可以留在本区、带回结束或单向深入；最终 Boss 全部领奖后进入通关结算。
- 普通与精英死亡推动独立技能成长；Boss 提供完整装备或收藏品多轮选择，箱子与商人使用各自固定内容。旧额外随机装备发奖和宝箱附送技能选择不再接入。
- 保存覆盖完整战斗、区域生命、交互、物品、奖励队列与终局，异常后继续同一局；收藏仅按成功带回实际入库的物品登记，成就以稳定身份提供永久属性来源。
- 三张完整地图资源、大小地图、出口界面、收藏界面、配置适配、统计报告与旧无引用资产清理已经接入。当前仍使用占位模型和可调原型参数。
- HUD 直接预告最终 Boss 与弱点，“本局总览”可重看冻结的区域地图、Boss、收藏目标及已获强化；未进入区域只显示情报，不提前生成内容。大地图支持定位玩家，目标详情显示配置名称、明确标注的直线距离，以及精英和 Boss 的配置弱点；小地图为远处未完成 Boss 显示边缘指向。
- 收藏候选、商人物品和宝箱摘要使用已经入库确认的“已收藏/未收藏”状态；区域出口展示全部待带回物品数量、冻结回收估值、扣除入场与购买支出的净资产变化、新收藏种数及击杀经验，预览不发放金币或登记收藏。
- 普通/精英首次击杀与复活击杀分别统计技能进度和经验，Boss 领奖轮数与技能选择分开，区域有效停留与完成状态一同保存；结果和战绩区分最终通关、提前带回、死亡与放弃，旧记录未保存的新字段明确显示“未记录”。

## 4 生命周期与恢复边界

1. **准入**：统一保存体力扣除、携入托管、RunId 与 v2 活动版本，冻结 Boss/地图请求。场景绑定首次生成当前区域；完整边界确认后开放模拟。
2. **死亡与复活**：稳定槽位保存 `LifeSequence`、`CurrentActorId`、已处理生命序号与时钟；同生命死亡只消费一次。经验、技能贡献、Boss 待领奖事实处理后才确认消费序号。初生生命为 1；复活提交后递增，ActorId 在整关全局递增且不复用。旧尸体通过 `TryRetireDeadActor` 回收，旧飞弹和迟到来源不会指向新生命。
3. **安全出生**：到期后检查原出生点占位、玩家安全距离与战斗相机可见性；条件连续满足才推进预警，失效退回等待。区域离开、暂停、展开地图、领奖和保存门禁不推进区域有效 tick；恢复不补离线时间。
4. **交互与奖励**：箱子冻结完整物品及领取身份，NPC 冻结商品、价格及售出状态；技能资格、候选、选择结果与 Boss 各轮物品纳入同一完整快照。关键保存确认前禁用操作并隐藏未确认奖励候选。
5. **区域转换**：只允许完成尾王及其领奖后单向进入下一域；生命、技能、Buff、冷却、背包和成长余量延续，不回满、不再次扣体力。转换保存确认后公布目标场景与地图。
6. **终局**：玩家与 Boss 同 tick 死亡先展示死亡选择，不打开胜利领奖窗口；广告复活并完成保存后继续原奖励队列，选择结算返回才冻结死亡终局。最终 Boss 不能跳过待领奖直接结算。已保存终局优先继续原结算，不能恢复为此前活着的关卡。

`ExpeditionSnapshotCodec` 将完整状态分成稳定组件，保存 manifest、请求与区域计划、槽位状态、战斗角色/施法/位移/飞弹/Buff、物品与奖励等；`SaveStateJournal` 保存完整检查点及连续增量。唯一串行泵冻结原候选，达到预算或保存失败后阻止继续模拟，重试同一修订；局外保存先排空局内队列，再取得独占门禁。

恢复校验 RunId、活动版本、内容版本、MapId/Version、区域/玩家对应关系、物品唯一归属与奖励队列。完整战斗恢复包含随机游标和来源/目标引用，不重放旧伤害、收益或选择，也不重抽已生成内容。

**历史活动局**：`ActiveRunVersion = 0` 的旧活动记录不清档、不自动退款、不按 v2 继续关卡；协调器保留原存档并阻塞续关，等待独立迁移决策。当前新准入取消与未激活入场补偿仍受专门边界约束，不作为已运行 v2 单局异常退出的退款路径。

连续战斗会形成待提交完整 tick，不能据此宣称“最后已展示 tick 零丢失”。硬终止恢复到最新完整持久修订。第 6.2 节已测量文件保存压力下的确认延迟、冷恢复与最终 tick 差；该诊断先排空保存队列再冷恢复，不证明写入途中硬终止时最后展示 tick 零丢失。目标设备成本与进程终止矩阵仍需单独验收。手动休整、云同步和多设备续接没有在本轮新增。
