# 属性系统分析与完善方案

更新日期：2026-10-18。

当前项目已有八项通用战斗属性，另有移动速度、攻击范围两个基础字段。完善重点是补齐攻击节奏、技能形态、续航等构筑方向，并统一装备、成长和 Buff 的属性来源、叠加与展示规则。

本文保存属性系统的现状分析与完善方案；现状基于 2026-10-17 的源码和配置核查，新增属性、计算规范与实施顺序尚未落地。市场参考不构成项目规则，建议数值与后续扩展不视为已经确认的平衡参数。

## 1 市场参考与属性分类

| 参考游戏 | 属性设计重点 | 对本项目的价值 |
| --- | --- | --- |
| Brotato | 攻击速度、伤害、暴击、防御、闪避、再生、生命偷取、范围，以及幸运和经济成长 | 让输出、生存、续航、经济形成不同投资方向 |
| Vampire Survivors | 伤害之外提供冷却、数量、范围、持续时间、飞行速度 | 让强化改变技能覆盖和形态，形成直观的成长反馈 |
| Soulstone Survivors | 施放频率、多重施放、范围、暴击，以及针对技能类别的强化 | 支持围绕技能类别构筑，并区分全局加成与指定技能加成 |

参考公开属性资料：[Brotato Stats](https://brotato.wiki.spellsandguns.com/Stats)、[Vampire Survivors PowerUps](https://vampire-survivors.fandom.com/wiki/PowerUps)、[Soulstone Survivors Attributes](https://soulstone-survivors.fandom.com/wiki/Attributes)。这些资料由社区维护，本文参考属性分类与构筑方向，不直接采用其数值和计算公式。同名属性在不同游戏中的语义可能不同，例如生命偷取不必然表示按实际伤害比例回血。

| 类别 | 常见属性 | 解决的问题 |
| --- | --- | --- |
| 基础输出 | 攻击、增伤、暴击率、暴击伤害 | 每次命中有多强 |
| 输出节奏 | 攻击速度、技能冷却、多重施放 | 多久攻击一次、一次释放多少 |
| 技能形态 | 攻击距离、效果范围、数量、持续时间、弹速、穿透、弹射 | 覆盖多少敌人、如何命中 |
| 生存与续航 | 生命、防御、减伤、闪避、回血、吸血、护盾 | 承受伤害与恢复的能力 |
| 特定流派 | 持续伤害、异常触发、特定技能增伤、破甲、反击 | 形成有区别的构筑 |
| 探索与成长 | 移速、经验获取、幸运、金币获取、拾取范围 | 战斗外的效率、成长和收益 |

属性是否加入，以对应玩法、实际受益对象和可形成的选择为依据，不以覆盖全部分类为目标。

## 2 当前已实现能力

### 2.1 八项通用战斗属性

装备的 `ProjectAttributeType` 与战斗的 `CombatAttributeKind` 均包含以下八项。

| 属性 | 标识 | 当前实际含义 |
| --- | --- | --- |
| 生命上限 | `MaxHealth` | 决定最大生命；局内永久生命上限强化同步回复实际增加的生命 |
| 攻击力 | `Attack` | 参与技能伤害公式；治疗效果也支持配置攻击力系数 |
| 防御 | `Defense` | 承伤倍率为 `100 / (100 + Defense)` |
| 暴击值 | `CriticalRating` | 暴击率为 `R / (R + 100)`，不是直接百分比 |
| 暴击伤害 | `CriticalDamage` | 暴击后的总倍率；`1.5` 表示造成 150% 伤害 |
| 闪避率 | `DodgeChance` | 对允许闪避的伤害进行概率判定；当前上限为 75% |
| 伤害加成 | `DamageIncrease` | 伤害乘以 `1 + DamageIncrease` |
| 伤害减免 | `DamageReduction` | 防御之后，伤害再乘以 `1 - DamageReduction`；当前上限为 75% |

伤害先判闪避，再计算以下乘区，实际扣血不超过目标剩余生命：

```text
伤害 = max(0, 固定伤害 + 攻击力 × 攻击系数)
     × (1 + 伤害加成)
     × 暴击倍率（未暴击为 1）
     × 100 / (100 + 目标防御)
     × (1 - 目标伤害减免)
     × 技能词条伤害倍率
     × 目标针对该效果 ID 的弱点倍率
```

例如防御 100 将伤害降低至一半，再有 20% 减伤，最终承受原伤害的 40%。防御和伤害减免具有不同计算位置。

源码入口：[CombatTypes.cs](../../../DevProject/Assets/Scripts/GameLogic/Runtime/Gameplay/Combat/CombatTypes.cs)、[CombatWorld.Attributes.cs](../../../DevProject/Assets/Scripts/GameLogic/Runtime/Gameplay/Combat/CombatWorld.Attributes.cs)、[CombatWorld.Systems.cs](../../../DevProject/Assets/Scripts/GameLogic/Runtime/Gameplay/Combat/CombatWorld.Systems.cs)。技术保护上限不代表已经完成玩法平衡。

### 2.2 已有但尚未统一为成长属性的能力

| 能力 | 当前状态 | 尚缺的部分 |
| --- | --- | --- |
| 移动速度 | 有基础字段，局外敏捷技能提高移速，Buff 可临时加值 | 未进入通用属性枚举，普通词条、收藏和纯属性奖励不能直接配置 |
| 攻击范围 | 有基础字段，武器提供范围，专用强化及 Buff 可修改 | 主要作用于标记为使用角色攻击范围的普攻准入与效果半径，不自动影响所有技能 |
| 普攻速度 | 疾风通过冷却倍率同步缩放普攻时间轴和冷却 | 没有统一的角色攻速属性 |
| 技能冷却 | 技能有冷却配置，底层支持指定技能冷却倍率 | 没有统一的角色技能冷却属性；普通技能冷却倍率不缩短施法动作 |
| 技能范围与伤害倍率 | 已有专用词条倍率，横扫、重击等正在使用 | 尚未作为统一属性贯通装备、成长和面板 |
| 飞弹数量、弹速、穿透与反弹 | 有数量、速度、目标数、反弹次数及命中间隔等配置 | 当前是技能或飞弹参数，没有角色级成长加成 |
| 持续时间 | 技能、Buff、飞弹具有相关时间配置 | 没有通用限时效果持续时间加成 |
| 治疗与周期回血 | 支持治疗和周期执行治疗；复苏已有实际内容 | 没有治疗增幅、生命再生或伤害吸血属性 |
| 击杀回复、反击、暴击追伤 | 已有触发机制和实际配置 | 属于被动机制，不是通用数值属性 |
| 流血与持续伤害 | 已有流血和周期伤害执行能力 | 没有通用持续伤害加成、异常强度等成长属性 |

当前猎杀回复和嗜血追猎都是击杀后固定回复，不是按实际伤害比例吸血。命中、暴击、击杀、受伤触发已存在，触发效果可配置治疗，但当前没有向触发治疗传递本次实际伤害量。

当前弱点按特定伤害效果 ID 匹配，尚未建立物理、火焰、冰霜等通用伤害分类与抗性体系，也未建立护盾池、格挡和完整控制状态契约。

源码入口：[CombatCatalog.cs](../../../DevProject/Assets/Scripts/GameLogic/Runtime/Gameplay/Combat/CombatCatalog.cs)、[CombatWorld.Augments.cs](../../../DevProject/Assets/Scripts/GameLogic/Runtime/Gameplay/Combat/CombatWorld.Augments.cs)、[CombatWorld.Projectiles.cs](../../../DevProject/Assets/Scripts/GameLogic/Runtime/Gameplay/Combat/CombatWorld.Projectiles.cs)。

### 2.3 当前内容与成长来源

八项通用属性均有普通装备词条和局内纯属性奖励。当前局内每级奖励为生命上限 +20、攻击 +4、防御 +8、暴击值 +12、暴击倍率 +0.2、闪避率 +0.05、增伤 +0.1、减伤 +0.05，每项最多三级；这些仍为可调原型值。

收藏成就目前实际覆盖生命、攻击、防御，五项全部完成合计生命 +18、攻击 +3、防御 +2。局外力量、生存、敏捷技能分别提高攻击、生命、移速；角色等级本身不直接增加战斗属性，升级发放技能点。

当前局外汇总顺序：

1. 读取基础生命、暴击倍率、攻击范围和移速。
2. 汇总穿戴装备基础属性和普通词条；武器提供攻击范围。
3. 未穿武器时追加裸攻。
4. 对已有攻击施加力量百分比加成，增加生存技能提供的固定生命，对移速施加敏捷百分比加成。
5. 加入收藏成就属性，再执行各属性限制。

因此力量会放大装备攻击，但不会放大之后加入的收藏攻击。局内永久属性强化以独立增量加入战斗世界，也不会重新经过局外力量倍率。该差异应明确成为规则，或在统一属性计算时调整。

战斗世界已经区分基础属性和八项累计局内增量，词条支持按来源组替换；尚未建立覆盖所有属性的通用来源条目与撤销规则。换装替换基础生命上限只截断当前生命，不自动补血；局内生命上限强化则回复实际增量，两者当前有明确区别。

内容和源码入口：[CfgRogueRewards](../../../DevProject/Assets/GameResources/Config/Tables/Table_CfgRogueRewards.json)、[CfgCollectionAchievements](../../../DevProject/Assets/GameResources/Config/Tables/Table_CfgCollectionAchievements.json)、[ProjectEquipment.cs](../../../DevProject/Assets/Scripts/GameLogic/Runtime/Project/ProjectEquipment.cs)、[ProjectModels.cs](../../../DevProject/Assets/Scripts/GameLogic/Runtime/Project/ProjectModels.cs)。

### 2.4 面板与状态边界

角色面板目前读取局外已保存的装备与成长结果，只展示八项属性，没有移速和攻击范围，也不读取完整的局内强化与 Buff 结果。暴击值会同时显示换算概率；来源明细主要只有收藏成就。

等级、长期经验、体力、金币、钻石、技能点属于长期成长或资源。当前生命、技能剩余冷却属于运行状态，均不应与可叠加的战斗属性混为一类。

源码入口：[CharacterStatsWindow.cs](../../../DevProject/Assets/Scripts/GameLogic/Runtime/UI/Character/CharacterStatsWindow.cs)、[ProjectSession.cs](../../../DevProject/Assets/Scripts/GameLogic/Runtime/Project/ProjectSession.cs)。

## 3 建议的属性扩展顺序

### 3.1 第一批核心属性

将现有八项与移速、攻击范围统一为十项基础属性，再新增或通用化以下六项，形成首版十六项核心属性。

| 建议属性 | 作用 | 当前内容的受益方向 |
| --- | --- | --- |
| 攻击速度 | 提高基础攻击频率，维持动作与伤害时间轴一致 | 三类武器、高速攻击、暴击和命中触发构筑 |
| 技能冷却缩减 | 缩短普通技能释放间隔 | 裂地斩、追魂飞剑、复苏等技能循环 |
| 效果范围加成 | 扩大符合条件的伤害或作用区域 | 范围清怪，与武器攻击距离区分 |
| 额外飞弹数量 | 增加支持数量成长的飞弹 | 飞剑和可扩展的多飞弹构筑 |
| 限时效果持续时间加成 | 延长符合条件的 Buff、持续技能或飞弹寿命 | 持续伤害、临时增益和持续覆盖 |
| 治疗效果加成 | 提高明确纳入范围的技能治疗和触发治疗量 | 复苏、击杀回复等续航方向 |

适用边界：

- 攻击距离与效果范围分别定义，避免一个属性同时隐式改变追敌距离、武器触及和全部技能覆盖。
- 限时效果持续时间不等于施法动作时长，不应让挥刀变慢；永久环绕效果不获得无意义的持续时间收益。周期频率是否改变另行定义，不随持续时间默认改变。
- 数量只作用于支持数量成长的技能，裂地斩、复苏不机械套用飞弹数量。
- 普攻速度与普通技能冷却分开，保留武器节奏流与技能循环流的区别。
- 属性必须有明确受益对象；奖励候选检查当前技能、前置关系和上限，避免出现无法受益的选项。

### 3.2 第二批续航与流派属性

| 方向 | 建议候选 | 采用条件 |
| --- | --- | --- |
| 续航 | 生命再生、命中回复、伤害吸血 | 区分每秒回复、每次命中回复和按实际伤害回复，不必同时大量投放 |
| 伤害专精 | 普攻增伤、技能增伤、飞弹增伤、持续伤害增伤 | 先建立技能或伤害标签，限定作用对象 |
| 异常构筑 | 异常触发概率、持续伤害强度、异常持续时间 | 先服务流血，再决定是否加入燃烧、中毒等机制 |
| 破防 | 防御穿透、降低目标防御 | 敌人防御差异足以形成应对选择后加入 |
| 飞弹特化 | 弹速、穿透数量、弹射次数 | 优先作为指定技能强化或高级词条，控制通用池规模 |

续航会改变探索过程中的消耗压力。优先加强已有复苏与击杀回复，再决定是否开放普遍的持续再生和伤害吸血。

### 3.3 随对应玩法扩展的属性

- 护盾容量与恢复：先定义护盾获得、吸收、恢复、持续和清除规则。
- 格挡率与格挡减伤：先定义与闪避、防御的区别。
- 元素伤害与抗性：先建立伤害类型及对应技能和敌人。
- 控制抗性与韧性：先建立眩晕、冻结、减速等控制契约。
- 幸运、经验获取与金币获取：明确影响对象、生成时点和结算时点。

经验需要区分长期角色经验与局内 Rogue 成长进度。当前多区域设计采用首次生成后固化的奖励规则，幸运不能通过重复打开界面重新抽取既定结果；关卡结构调整时需同步明确生成边界。

当前没有经验球自动拾取玩法，不直接引入经验拾取半径。现有交互半径同时影响宝箱、商人、出口等对象，不适合作为掉落拾取属性直接扩展。当前也没有需要魔力或能量消耗的技能循环，不为补齐属性列表单独加入魔力、力量、敏捷、智力等额外中间层；现有同名局外技能仍按其实际效果处理。

## 4 统一计算与展示规范建议

### 4.1 加法与倍率

为普通数值属性建立默认顺序：

```text
最终属性 = (基础值 + 固定加值合计) × (1 + 百分比加成合计) × 独立倍率
```

随后应用该属性的上下限。概率、数量、冷却等使用明确的专用规则，不要求强套同一公式。只有有明确玩法理由的效果才进入独立倍率，避免同类来源因实现位置不同产生意外乘区。

装备、收藏、局外技能和局内成长是否享受同一百分比，应在实施时明确；暴击值继续使用单一概率换算入口，不同时引入两套独立暴击率计算。上下限、单位、显示精度及舍入规则统一配置或定义，避免局外和战斗端各自维护不同口径。

### 4.2 来源与撤销

覆盖基础、装备基础属性、普通词条、局外技能、收藏成就、局内强化和临时 Buff。每项修正应能识别来源、作用对象、运算方式与有效期，支持整体重算或按来源撤销。

换装、Buff 到期和恢复采用相同的计算规则。生命上限变化是否补血、技能冷却是否受当前属性变化影响等状态转换必须独立定义，避免借重算恢复生命或重置冷却。

### 4.3 属性 状态 机制与行为

| 类型 | 示例 |
| --- | --- |
| 属性 | 攻击力、治疗加成、护盾容量 |
| 状态 | 当前生命、当前护盾、剩余冷却 |
| 触发机制 | 暴击追加攻击、击杀回血、受伤反击 |
| 技能行为 | 飞剑追踪方式、环绕轨迹、目标丢失后的行为 |

各层通过明确接口组合，不将全部内容塞入同一属性枚举。

### 4.4 面板与奖励池

角色面板区分局外结果和局内实时结果，显示主要来源、固定加值和百分比加成。暴击值同时显示实际暴击率，攻速和冷却显示对应攻击或释放间隔，范围类说明实际影响对象。

候选池按当前技能、前置条件、互斥关系和上限过滤。对永久效果不投放无效的持续时间加成，对不支持多飞弹的技能不投放数量加成。

## 5 实施与验收边界

推荐顺序是统一现有十项属性及来源规则，接入六项核心扩展与面板，再增加续航和伤害专精，最后随新玩法扩展护盾、元素等系统。

正式属性、词条、技能适用范围和可调数值继续以 `config/excel` 为唯一内容源。实施时同步修改生成表、局外汇总、战斗属性、装备和奖励候选、保存结构、UI 与对应测试，不保留并行旧属性计算路径。

验收重点应覆盖真实交互：不同来源的叠加与移除、换装与 Buff 到期、生命上限变动、普攻时间轴和普通技能冷却、数量与持续时间适用条件、奖励有效性、局内外面板以及保存恢复一致性。项目当前使用内存后端，运行内恢复不等于跨启动持久化验收。

本文仅保存分析与方案，没有完成上述代码和配置改造，也不改变现行关卡、物品结算或广告规则。当前源码状态仍以[多区域玩法实现与验收](多区域玩法实现与验收.md)为准。
