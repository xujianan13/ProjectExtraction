## 文档与代码约定

- 新的项目设计、决策、实现和验收写入 `v3`；V1/V2 只补充必要的历史勘误、版本提示和链接修复。
- V1/V2 正文中的“当前”“已确认”和测试结果属于当时的版本，不自动成为 V3 的规则或验收证据。
- 继续适用的战斗、装备、属性分析、配置与平台规范，按 [V3 文档承接清单](v3/文档承接清单.md)的具体范围采用。建议与待定项不因承接而变成已批准规则。
- **工程只维护一套有效实现。** 按 V3 阶段原位改造，同批删除被替代的业务代码、配置、调用入口、测试和无引用资产；不恢复 V1 旧代码，不建立旧版备用副本、版本开关或双轨实现。
- 仍适用的战斗、物品、交易和框架能力继续复用。V2 当前代码作为改造起点，不因文档归档立即删除。
- 本次目录整理不等于玩法迁移；实际替换与验证随 V3 阶段完成。历史玩家数据不因归档删除，存档迁移独立决定。

通用框架文档继续维护在 [docs/framework](../framework/README.md)，不参与本项目玩法版本划分。工程操作和开发约束见[仓库说明](../../README.md)与[项目工作指引](../../AGENTS.md)。
