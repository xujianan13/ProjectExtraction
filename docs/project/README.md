## 文档与代码约定

- 新项目设计、决策、实现和验收写入 `v3`；V1/V2 只补充必要历史勘误、版本提示和链接修复。
- V1/V2 正文中的“当前”“已确认”和测试结果属于当时版本，不自动成为 V3 规则或验收证据。
- 稳定战斗、物品、配置、框架与平台规范按 [V3 承接清单](v3/文档承接清单.md)采用；十六项属性等未实施建议不能当作已有能力。
- 工程只维护一套有效实现，原位改造并删除已替代业务、配置、入口、测试与无引用资产，不恢复 V1 或建立 V2/V3 双轨。
- 当前保持 Memory，原有磁盘档不读、不写、不删；旧活动局及历史数据迁移独立决定，不自动清档或退款。
- V3 实际通过范围、证据与限制统一记录在[实施计划与验收](v3/实施计划与验收.md)，不借用历史测试结果。

通用框架文档维护在 [docs/framework](../framework/README.md)，不参与玩法版本划分。工程操作与约束见[仓库说明](../../README.md)和[项目工作指引](../../AGENTS.md)。
