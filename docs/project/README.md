# 项目文档

本目录是 ProjectExtraction 项目文档的根目录，用于维护需求、3D 搜打撤与 Roguelike 玩法设计、项目决策、Mobile/微信/PC 适配及本项目验收。

## 玩法设计入口

- [核心玩法设计](核心玩法设计.md)：已确认的玩法与结算规则，后续模块设计以此为准。
- [玩家主要属性与货币设计](玩家主要属性与货币设计.md)：等级、经验、体力、金币、钻石的数据口径，以及战利品出售和双币交易。
- [角色属性与装备词条](角色属性与装备词条.md)：八项战斗属性、武器/护甲、六档品质、随机词条、伤害计算和旧档迁移。
- [Roguelike 三选一设计与实现](Roguelike三选一设计与实现.md)：局内暂停选择、临时属性与物品奖励，以及默认关闭的刷新和第四选项授权。
- [技能成长设计](技能成长设计.md)：升级技能点、局外技能提升、持久化与角色技能效果边界。
- [关卡与地图设计](关卡与地图设计.md)：随机连通地图、未清图自由往返、回访状态与撤离建议。
- [ECS 战斗框架设计](战斗框架设计.md)：统一效果执行、技能时间轴、飞弹和 Buff，包含固定时序与跨图状态；首版实现与验证范围见[首版代码实现与验证](首版代码实现与验证.md)。
- [主界面设计](主界面设计.md)：Home 顶部五项属性、底部仓库与技能入口及响应式布局。
- [战斗摇杆与界面适配](战斗摇杆与界面适配.md)：1080×1920 默认竖屏、真实摇杆控制与布局验证。
- [主界面与关卡场景流程设计](主界面与关卡场景流程设计.md)：出战准入、场景就绪、终局保存、结果页、返场和异常恢复的设计；首版接入情况见[场景流程首版实现与验证](场景流程首版实现与验证.md)。
- [玩法模块与迭代计划](玩法模块与迭代计划.md)：模块责任、协作契约、可玩性验证目标、建议迭代顺序与待定决策。

## 战斗详细设计

- [技能时间轴与判定](战斗设计/技能时间轴与判定.md)：施法、0/5/10 帧示例、目标选择、范围判定与中断。
- [飞弹系统](战斗设计/飞弹系统.md)：直线、抛物线、瞬时、锁定追踪、连续碰撞和生命周期。
- [Buff 系统](战斗设计/Buff系统.md)：叠加、替换、重置时长、周期、属性句柄和结束原因。
